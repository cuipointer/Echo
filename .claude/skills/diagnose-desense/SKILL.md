# Diagnose Desense Skill

## 描述

启动 Desense 问题诊断流程，基于三要素模型和决策树进行问题分析。

## 触发条件

- 用户询问 Desense 问题诊断
- 用户提供受扰频段和测试场景
- 用户要求启动诊断流程

## 工作流程

### 1. 收集问题信息
- 受扰频段：WiFi 2.4G / WiFi 5G / LTE LB / LTE HB / GNSS L1 / GNSS L5
- 测试场景：Normal / LCD / DDR / VIDEO / VIB / FC / RC
- 干扰现象：灵敏度恶化程度

### 2. 执行决策树
- 根据受扰频段选择对应分支
- 根据测试场景选择子分支
- 获取可疑干扰源

### 3. 查询矩阵表
- 确认干扰源和受扰体组合
- 查询矩阵表获取 SOP 编号
- 如无对应 SOP，记录新组合

### 4. 输出诊断结果
- 干扰源分析
- 受扰体分析
- 耦合路径分析
- 可疑 SOP 编号

## 输出格式

```markdown
## 诊断结果

### 问题信息
- 受扰频段：[频段]
- 测试场景：[场景]
- 干扰现象：[现象]

### 干扰源分析
- 可疑模块：[模块列表]
- 优先级：[高/中/低]

### 受扰体分析
- 频段：[频段]
- 敏感度要求：[dBm 值]

### 耦合路径分析
- 可能类型：[传导/辐射/串扰/地弹]

### SOP 编号
- [SOP 编号]：[组合描述]
- [SOP 编号]：[组合描述]

### 下一步建议
1. [建议 1]
2. [建议 2]
```
