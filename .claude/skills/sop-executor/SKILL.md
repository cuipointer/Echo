# SOP Executor Skill

## 描述

按 SOP 标准化步骤执行 Desense 问题排查。

## 触发条件

- 用户要求执行特定 SOP
- 用户提供 SOP 编号
- 用户开始标准化排查流程

## 工作流程

### 1. 加载 SOP 文档
- 根据 SOP 编号查找文档
- 读取 SOP 内容
- 提取关键信息

### 2. 执行排查步骤
- 按 SOP 步骤执行
- 记录操作和结果
- 更新检查表

### 3. 输出执行报告
- 执行进度
- 操作记录
- 结论和建议

## SOP 结构

### 1. 组合信息
- 干扰源模块
- 受扰体频段
- 耦合路径类型

### 2. 理论预判
- 谐波命中计算
- 设计审查必查项

### 3. 软件排查步骤
- 场景复现
- 干扰源确认
- 频率验证
- 软件规避尝试

### 4. 硬件排查步骤
- 路径确认
- 硬件整改验证

### 5. 结论模板
- 三要素结论
- 改善措施

## 输出格式

```markdown
## SOP 执行报告

### SOP 信息
- 编号：[SOP 编号]
- 组合：[干扰源] → [受扰体]

### 执行进度
- [步骤 1]：[状态]
- [步骤 2]：[状态]
- ...

### 操作记录
#### 步骤 1：[步骤名称]
- 操作：[操作描述]
- 结果：[操作结果]
- 状态：[完成/进行中/阻塞]

### 结论
[执行结论]

### 建议
[下一步建议]
```
