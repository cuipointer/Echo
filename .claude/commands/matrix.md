# /matrix

用户输入:`$ARGUMENTS`

查询 [knowledge/matrix/](knowledge/matrix/) 下的核心矩阵表,返回对应 SOP 编号。

## 1. 解析参数

- **干扰源**:LCD / Camera / DDR / PMIC / VIB / Speaker / Charger / USB3 等
- **受扰体**:W24 / W5 / LLB / LHB / GL1 / GL5

若参数缺失 → 向用户索取;若用户只给一边 → 输出该干扰源/受扰体对应的整行/整列。

## 2. 查询逻辑

1. 读取 `knowledge/matrix/matrix-table.md`(或该目录下的最新矩阵文件)。
2. 按"干扰源 × 受扰体"定位单元格 → 得到 SOP 编号。
3. 若单元格为 `—` → 说明频率域无直接交叠,提示用户。
4. 若单元格加粗 → 说明是高频问题,优先级高。
5. 若用户只给一边,列出整行/列;若未指定 → 输出完整矩阵概览并提示可细化。

## 3. 输出格式

```markdown
## 矩阵查询结果

- 干扰源:[源]
- 受扰体:[频段]
- SOP 编号:[如 GL1-01]
- 组合描述:[一句话说明]
- 优先级:[高/中/低]
```

## 4. 后续动作

- 若用户要开始排查:建议 `/diagnose` 走完整决策流程,或直接调用 `sop-executor` skill 按编号执行。
- 若矩阵中无对应组合:建议在 `knowledge/matrix/` 下补充新组合。
