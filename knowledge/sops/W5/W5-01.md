# SOP-W5-01:系统时钟 (OSC / LCD MIPI) → WiFi 5G

**版本**:v0.9.0
**日期**:2026-05-06
**状态**:**方法论版(待现场复测)** — 从 placeholder v0.1 升级,基于 EMC 2024 A.1 案例反哺 + W24-01 结构频段改写,**未经现场实测验证**

> **复测提醒**:WiFi 5G 信道数量多(5150-5825 + UNII 扩展),本 SOP 的谐波命中表需按实际时钟频率逐一验算;不同机型时钟规划差异大。

---

## 一、组合信息

### 干扰源
- **模块**:系统时钟(OSC / XO)、LCD MIPI 时钟、CPU 主时钟 / PLL
- **代码**:OS / LM / CP
- **分类**:射频(时钟谐波类 — 窄带为主,可叠加宽带)
- **噪声来源**:晶振整数倍谐波、MIPI DSI Clock 边沿切换噪声、CPU PLL 倍频输出谐波
- **基频范围**:
  - OSC / XO:19.2 MHz、26 MHz、38.4 MHz、52 MHz(典型手机晶振)
  - LCD MIPI:60-150 MHz(DSI Clock Lane)
  - CPU / PLL 衍生时钟:100 MHz-1 GHz(SoC 内部参考)
- **典型干扰**:高次谐波(N=30~300)命中 5G 单信道,呈现"clock spur"特征 — 窄带、单信道、稳定

### 受扰体
- **频段**:WiFi 5G
- **代码**:W5
- **频率范围**:5150-5825 MHz(U-NII-1/2A/2C/3)+ U-NII-5/6/7/8(6 GHz 扩展)
- **敏感度要求**:-72 ~ -82 dBm(典型 802.11ac / ax 20 MHz/40 MHz/80 MHz)

### 耦合路径
- **主要类型**:**传导 + 辐射混合**
- **机制**:
  - 传导:时钟谐波沿电源平面 / 地平面进入 RF 前端 PA/LNA 供电,污染 RX 参考噪底
  - 辐射:LCD MIPI 高速差分走线天线化,通过空间耦合进入 WiFi 天线
  - 结构性:XO / MIPI 走线距 WiFi 天线过近,近场直接耦合

### 矩阵元信息
- **优先级**:P1
- **典型恶化量**:单信道 10-25 dB(窄带谐波 spur 典型特征)
- **快速诊断提示**:**单信道 ≥ 10 dB、邻道正常** → 按 [`bandwidth-discrimination.md`](../../methodology/bandwidth-discrimination.md) 判定为窄带谐波

## 二、理论预判

### 谐波命中计算

WiFi 5G 信道密集,时钟基频谐波极易命中。示例(按典型基频枚举):

| 基频 | 谐波次数 N | 命中频点 (MHz) | 对应 WiFi 5G 信道 | 备注 |
|---|:---:|---|---|---|
| 19.2 MHz | 300 | 5760 | ≈ CH152 / 5765 附近 | **EMC A.1 命中频点** |
| 19.2 MHz | 280 | 5376 | ≈ CH76(5G 低端 / 未分配) | — |
| 26 MHz | 215 | 5590 | CH118 | — |
| 38.4 MHz | 150 | 5760 | ≈ CH152 | XO 倍频可能 |
| 52 MHz | 111 | 5772 | ≈ CH154 | — |
| 100 MHz | 58 | 5800 | CH160 附近 | PLL 衍生时钟典型 |
| 120 MHz(MIPI) | 48 | 5760 | ≈ CH152 | MIPI 高次谐波 |

**结论**:19.2 MHz / 26 MHz / 38.4 MHz 系列 XO 的 200-300 次谐波,以及 MIPI / PLL 衍生时钟的 40-80 次谐波,对 WiFi 5G 全信道均存在命中风险;**需按实际硬件的时钟规划表逐一验算**。

可调用 `harmonic-calc` skill 或 `tools/harmonic_calc.py` 辅助计算。

### 设计审查必查项

1. **时钟规划 review**:覆盖所有 XO / PLL 输出频率,查谐波是否命中 5150-5825 + U-NII-5 全信道
2. **MIPI 阻抗匹配**:DSI Clock Lane 差分阻抗 / 共模抑制,阻抗失配会放大谐波辐射
3. **电源去耦**:XO 供电 / MIPI VDDI / RF 前端 VCC 之间的滤波网络(特别是 5G 频段的去耦电容自谐振)
4. **地平面完整性**:时钟走线下方地平面是否完整,避免 slot antenna 效应
5. **展频(SSC)配置**:MIPI / PLL 是否启用 SSC,调制深度 / 频率是否合理
6. **数字滤波器(digital filter)NV 配置**:RX 基带是否对特定 spur 频点启用 notch 滤波(**本 SOP 主路径**)

## 三、软件排查步骤

### 步骤 1:场景复现

**目标**:确认 WiFi 5G 单信道窄带恶化可复现

**操作**:
1. 在 Normal 场景下(屏幕暗 / 无 Camera / 无充电)扫描 5G 全信道灵敏度
2. 带宽覆盖:20 MHz / 40 MHz / 80 MHz 三档分别测
3. 记录每信道 Desense 值,画出信道平坦度曲线
4. 识别尖峰:**单信道 ≥ 10 dB、邻道正常** → 按 [`bandwidth-discrimination.md`](../../methodology/bandwidth-discrimination.md) 判定为窄带谐波

**预期结果**:某 5G 单信道明显凸起(典型 10-25 dB),呈 spur 特征

### 步骤 2:干扰源确认

**目标**:锁定时钟类干扰源(OSC / MIPI / PLL)

**操作**:
1. **关显示测试**:`adb shell input keyevent 26`
   - 干扰消失或显著减小 → LCD MIPI 相关
   - 干扰不变 → OSC / PLL / CPU 主时钟(显示无关的系统时钟)
2. **关高时钟负载测试**:停止 CPU 高负载任务、关 Camera / Modem 高速功能
   - 干扰变化 → PLL / CPU 衍生时钟相关
   - 干扰不变 → XO(系统主晶振)相关
3. **频谱仪看 spur**:在恶化信道频点观察谱线,确认是否为稳定窄带尖峰

**预期结果**:定位到 OSC / MIPI / PLL 中的具体类别

### 步骤 2.5:子功能逐项排查(零成本验证)

**目标**:在时钟类内部进一步区分

**操作**(按零成本顺序):
1. **XO 切换**:若硬件支持多 XO 或软件可切换 XO 倍频档,切换后看 spur 频点是否移动
2. **SSC on/off**:开关 MIPI / PLL 展频,看 spur 幅度变化
   - SSC 开启后 spur 展宽且幅度降低 → 该时钟源确认
3. **关 LCD backlight PWM**:排除 PWM 谐波混淆(PWM 一般不命中 5G,但仍建议确认)
4. **只保留蓝牙 / 关 WiFi 2.4G 并行业务**:排除共存干扰(非时钟)

**预期结果**:确认具体时钟源(e.g. 某 PLL 倍频输出 / 19.2 MHz XO)

### 步骤 2.6:多源叠加排查

**触发条件**:步骤 2.5 排除单一时钟后仍有 spur,或多个 spur 频点重叠

**操作**:按 [`_template.md` 步骤 2.6](../_template.md) 多源叠加排查法

候选源枚举:
- H1:OSC 主时钟谐波
- H2:MIPI DSI Clock 谐波
- H3:CPU PLL / SoC 内部衍生时钟
- H4:RF transceiver 自身本振泄露(与时钟谐波重叠)

### 步骤 3:频率验证

**目标**:频谱仪定位 spur 频点,反推时钟源

**操作**:
1. 频谱仪扫 5150-5825 MHz(必要时扩展 U-NII-5/6 到 7125 MHz)
2. 记录 spur 中心频率 f_spur
3. 反推:f_spur / N = 可能基频,在时钟规划表中匹配
4. 改变时钟配置(切 XO / 改 PLL 倍频)验证 spur 是否移动

**预期结果**:spur 频率与某时钟基频的 N 次谐波一致

### 步骤 4:软件规避尝试(**本 SOP 主路径 — 软件优先**)

**目标**:在软件层面消除或压低 spur,避免拆机

**操作**(按 EMC A.1 案例证明的顺序):

1. **数字滤波器(digital filter)NV 调参** ★★★ 主推
   - RX 基带对 spur 频点开 notch / 调 FIR 系数
   - 典型改善:**10-20 dB(EMC A.1 案例实测从 20 dB 恶化 → 解决到限值内)**
   - 优势:零成本、不拆机、可 OTA
2. **展频深度调整**:MIPI / PLL SSC 调制深度从 ±1% 调到 ±2%~±3%,看 spur 是否展宽降幅
3. **切换 XO 频率**(若硬件支持):由 19.2 MHz → 38.4 MHz 等切换,让谐波错开 5G 信道
4. **RX 前端滤波增强**:若射频方案支持动态滤波器配置,针对受扰信道切换参数
5. **信道避让**(权宜):业务层优先干净信道,临时方案

**预期结果**:大多数 spur 类 5G Desense 可在软件侧解决,**优先于硬件改版**。

## 四、硬件排查步骤(次要路径,软件无效时)

**触发条件**:软件 NV 调参 + SSC + 频率切换均无法达到限值

### 步骤 1:近场定位

**目标**:找到 spur 最强辐射点

**操作**:
1. 近场探头扫描 XO / MIPI FPC / PLL 相关 IC / 电源退耦区域
2. 在 spur 频点观察最强泄露源
3. 临时屏蔽该区域,看 5G 恶化是否改善

**预期结果**:定位辐射最强节点

### 步骤 2:时钟 / MIPI 通路整改

| 整改点 | 措施 | 预期改善 |
|---|---|:---:|
| XO 输出线 | 串磁珠 / 增加 pi 滤波 | 2-4 dB |
| MIPI Clock Lane | 包地过孔密度 / 差分阻抗调整 | 3-6 dB |
| XO / PLL 屏蔽 | 加局部屏蔽罩 / 导电泡棉 | 3-5 dB |
| 电源去耦 | 加高频去耦电容(5G 谐振点) | 1-3 dB |
| WiFi 天线隔离 | 增加天线与时钟源距离 / 优化方向 | 2-4 dB |

### 步骤 3:PCB 层叠改版(最后手段)

| 整改点 | 措施 | 预期改善 |
|---|---|:---:|
| 时钟走线层 | 移到内层并加完整参考地 | 3-5 dB |
| 地平面 | 修补 slot,增加缝合过孔 | 2-4 dB |
| MIPI 走线 | 缩短长度 / 避开 WiFi 天线净空 | 3-6 dB |

**预期结果**:综合改善到内部限值(≤ 3 dB)

## 六、典型案例

### 案例 1:O2 WiFi 5G CH153 (5765 MHz) Normal 20 dB — **本 SOP 首源案例**

- **问题描述**:O2 机型 Normal 场景下 WiFi 5G 5765 MHz 单信道恶化 20 dB,邻道正常(典型 spur 特征)
- **根因定位**:19.2 MHz XO × 300 = 5760 MHz,落在 CH153(5765 MHz)-5 MHz 边沿内
- **解决方案**:**数字滤波器 NV 调参**(RX 基带对 5765 MHz 附近开 notch)
- **改善效果**:从 20 dB → 限值内(< 3 dB),约 17 dB 改善
- **周期**:21 天(诊断 + NV 调参 + 回归测试)
- **方法论命中**:
  - ★ **"软件优先"原则命中** — 未拆机即解决,避免 PCB 改版周期
  - ★ 单信道 ≥ 10 dB → 按 `bandwidth-discrimination.md` 正确判定为窄带谐波 spur
  - ★ 三要素完整:干扰源(OSC 19.2 MHz)/ 受扰体(W5 CH153)/ 路径(传导)
- **参考**:[EMC-2024-Desense-triage.md A.1](../../cases/EMC-2024-Desense-triage.md) / [O2-W5-OSC-spur.md](../../cases/O2-W5-OSC-spur.md)

## 八、附录

### 术语表
- **XO**:Crystal Oscillator,晶体振荡器(系统主时钟源)
- **OSC**:Oscillator,振荡器泛称
- **SSC**:Spread Spectrum Clocking,展频时钟(通过频率调制降低谐波峰值能量)
- **NV**:Non-Volatile(item),非易失配置项,射频 / 基带参数存储单元,**OTA 可下发**
- **U-NII**:Unlicensed National Information Infrastructure,WiFi 5G/6G 免授权频段(U-NII-1/2A/2C/3/5/6/7/8)
- **digital filter**:数字滤波器,RX 基带 DSP 可配置的 FIR/IIR,针对特定频点 notch
- **MIPI DSI**:Mobile Industry Processor Interface Display Serial Interface
- **PLL**:Phase-Locked Loop,锁相环(SoC 内部时钟倍频)
- **spur**:spurious emission,离散窄带寄生辐射(时钟谐波的典型形态)

完整术语见 [knowledge/glossary.md](../../glossary.md)。
