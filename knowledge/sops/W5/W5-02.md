## 一、组合信息

### 干扰源
- **模块**：Camera System
- **噪声来源**：MIPI CSI Clock / Data、MCLK、AVDD 电源 SSN
- **基频范围**：MIPI CSI(200-800MHz)、MCLK(24-27MHz)、AVDD SSN(宽带噪声)

### 受扰体
- **频段**：WiFi 5G
- **频率范围**：5150-5850 MHz
- **敏感度要求**：-65 ~ -75 dBm（接收灵敏度）

### 耦合路径
- **类型**：辐射耦合、传导耦合
- **机制**：MIPI CSI高次谐波辐射 → 空间传播 → WiFi天线接收；电源高频噪声传导

## 二、理论预判

### 谐波命中计算

#### MCLK谐波分析
MCLK典型值为24MHz或27MHz：
- 24MHz × 214.6 = 5150.4MHz ✓ 命中WiFi 5G低端
- 24MHz × 243.75 = 5850MHz ✓ 命中WiFi 5G高端
- 27MHz × 190.7 = 5149MHz ✓ 命中WiFi 5G低端

#### MIPI CSI谐波分析
高分辨率配置更容易产生高频谐波：
- 4K分辨率，30fps，10bit，4 Lane：MIPI Clock ≈ 400MHz
- 400MHz × 12.875 = 5150MHz ✓ 命中WiFi 5G低端
- 400MHz × 14.625 = 5850MHz ✓ 命中WiFi 5G高端

**结论**：Camera高次谐波可能命中WiFi 5G频段，高分辨率场景风险更大

### 设计审查必查项
1. **高分辨率风险评估**：4K/8K摄像的MIPI频率规划
2. **MCLK谐波控制**：高频谐波的滤波和屏蔽设计
3. **电源高频噪声**：AVDD在5GHz频段的噪声抑制
4. **FPC高频屏蔽**：5GHz频段的屏蔽有效性验证
5. **天线隔离设计**：WiFi 5G天线与Camera的间距要求
6. **共模滤波高频扩展**：确保滤波网络覆盖5GHz频段

## 三、软件排查步骤

### 步骤 1：场景复现
**目标**：确认Camera相关干扰现象可复现

**操作**：
1. 进入测试场景：前摄/后摄高分辨率预览或录像
2. 测量WiFi 5G性能：记录吞吐量、RSSI、MCS等级等指标
3. 扫描各信道：检查36/100/149/165等关键信道
4. 分辨率阶梯测试：从低到高切换分辨率观察影响

**预期结果**：高分辨率Camera场景下WiFi 5G性能恶化

### 步骤 2：干扰源确认
**目标**：确认干扰源为Camera相关模块

**操作**：
1. 关闭Camera应用：观察干扰是否消失
2. 分辨率影响测试：对比1080p/4K/8K的干扰差异
3. 帧率影响测试：对比不同帧率的干扰程度
4. 前后摄对比：确认特定模组问题

**预期结果**：确认干扰与Camera分辨率和MIPI频率相关

### 步骤 3：频率验证
**目标**：验证干扰频率与理论预判一致

**操作**：
1. 读取当前MIPI Clock配置：重点关注高分辨率模式
2. 计算高次谐波：验证12-15次谐波与5GHz频段关系
3. 频谱仪观察：使用高频探头观察5GHz频段干扰
4. 信道分布分析：确认干扰是否集中在特定信道

**预期结果**：高频谐波命中WiFi 5G频段

### 步骤 4：软件规避尝试
**目标**：尝试软件措施改善干扰

**操作**：
1. 尝试MIPI SSC：
   - 开启高频SSC功能（调制率可调）
   - 测量改善效果：记录高频性能恢复
2. 尝试分辨率优化：
   - 适当降低分辨率（4K→1080p）
   - 测量改善效果：记录性能权衡
3. 尝试编码优化：
   - 调整编码参数减少数据量
   - 测量改善效果：记录画质与性能平衡

**预期结果**：WiFi 5G性能可接受恢复

## 四、硬件排查步骤

**触发条件**：软件措施无效或画质损失不可接受

### 步骤 1：路径确认
**目标**：确认5GHz频段耦合路径

**操作**：
1. 高频近场扫描：使用5GHz频段专用探头
2. FPC高频屏蔽测试：验证5GHz屏蔽效果
3. 电源高频噪声测量：使用频谱分析仪高频档
4. 天线隔离验证：外接天线测试布局影响

**预期结果**：确认5GHz干扰的主要传播路径

### 步骤 2：硬件整改验证
**目标**：验证高频干扰整改措施

**操作**：
1. 高频屏蔽增强：
   - FPC使用高频屏蔽材料
   - B2B连接器高频屏蔽处理
   - 测量改善效果：5GHz噪声降低
2. 高频滤波优化：
   - MCLK线路高频滤波电路
   - 电源高频去耦网络
   - 测量改善效果：高频谐波抑制
3. 结构高频优化：
   - 吸波材高频性能验证
   - 天线高频隔离设计

**预期结果**：WiFi 5G性能满足商用要求

## 六、典型案例

### 案例 1：4K录像WiFi 5G信道149失效
- **问题描述**：开启4K录像时，WiFi 5G信道149完全无法连接
- **解决方案**：降低录像分辨率到1080p，所有信道恢复正常
- **根本原因**：4K MIPI Clock 450MHz第13次谐波5745MHz命中信道149

### 案例 2：8K拍照WiFi吞吐量下降60%
- **问题描述**：8K连拍模式下，WiFi 5G吞吐量从867Mbps降到350Mbps
- **解决方案**：开启MIPI SSC并优化拍照缓存策略，吞吐量恢复到750Mbps
- **根本原因**：高数据量传输产生强高频谐波
