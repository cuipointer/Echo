## 一、组合信息

### 干扰源
- **模块**：LCD/OLED Display System
- **噪声来源**：MIPI Clock / OSC / 背光 PWM / TP 驱动
- **基频范围**：MIPI(60-120MHz) / OSC(24-48MHz) / 背光PWM(10-50kHz) / TP(100-400kHz)

### 受扰体
- **频段**：GNSS L1
- **频率范围**：1561-1606MHz
- **敏感度要求**：-140 ~ -150dBm

### 耦合路径
- **类型**：辐射耦合
- **机制**：MIPI走线辐射 → 空间传播 → GNSS天线接收

## 二、理论预判

### 谐波命中计算
LCD MIPI基频通常为60-120MHz，通过谐波分析：
- 60MHz × 26 = 1560MHz ✓ 命中GNSS L1低端
- 80MHz × 20 = 1600MHz ✓ 命中GNSS L1中段  
- 120MHz × 13 = 1560MHz ✓ 命中GNSS L1低端

**结论**：LCD MIPI谐波极易命中GNSS L1频段

### 设计审查必查项
1. **MIPI时钟规划**：检查是否预留SSC功能，避免基频谐波密集区
2. **Display电源滤波**：LCD(VSP/VSN/WLED)或OLED(ELVDD/ELVSS)滤波设计
3. **TP频率规划**：避免Tx频率谐波命中GNSS频段
4. **屏蔽接地设计**：LCD FPC屏蔽层完整性和接地，屏蔽盖密封

## 三、软件排查步骤

### 步骤 1：场景复现
**目标**：确认干扰现象可复现

**操作**：
1. 进入亮屏常亮场景
2. 测量GNSS L1灵敏度（GPS L1、BDS B1、GLONASS G1）
3. 记录恶化程度：通常5-15dB

**预期结果**：亮屏状态下GNSS L1灵敏度明显恶化

### 步骤 2：干扰源确认
**目标**：确认干扰源为LCD MIPI

**操作**：
1. 执行灭屏测试：`adb shell input keyevent 26`
2. 观察灵敏度变化：灭屏后应恢复正常
3. 排除其他干扰源：关闭相机、DDR等模块验证

**预期结果**：灭屏后干扰消失，确认LCD为干扰源

### 步骤 3：频率验证
**目标**：验证干扰频率与理论预判一致

**操作**：
1. 测量LCD MIPI实际时钟频率
2. 使用频谱仪观察GNSS L1频段的干扰频谱
3. 计算谐波关系：实际基频 × N = 干扰频率

**预期结果**：干扰频率与MIPI时钟谐波一致

### 步骤 4：软件规避尝试
**目标**：尝试软件措施改善干扰

**操作**：
1. **展频时钟（SSC）**：
   - 开启LCD MIPI SSC功能
   - 设置调制深度：±1% ~ ±3%
   - 测量改善效果：通常3-8dB改善

2. **频率调整**：
   - 调整MIPI时钟频率，避开敏感谐波点
   - 测试不同频率点的干扰程度
   - 选择最优频率：避免命中L1频段的频率

3. **功能开关**：
   - GPS定位时自动降低屏幕亮度
   - 关键定位场景关闭部分显示功能

**预期结果**：软件措施能带来显著改善

## 四、硬件排查步骤

**触发条件**：软件措施无效或改善不足

### 步骤 1：路径确认
**目标**：确认耦合路径类型

**操作**：
1. **近场扫描**：使用近场探头扫描LCD FPC区域
2. **屏蔽测试**：临时屏蔽LCD FPC，观察改善效果
3. **接地测试**：加强LCD屏蔽罩接地

**预期结果**：确认辐射耦合为主要路径

### 步骤 2：硬件整改验证
**目标**：验证硬件整改措施

**操作**：
1. **屏蔽整改**：
   - 增加LCD FPC屏蔽层厚度
   - 优化屏蔽层接地设计

2. **滤波整改**：
   - 在LCD电源线增加磁珠滤波
   - 优化MIPI时钟线滤波

3. **布局调整**：
   - 增加LCD与GNSS天线间距
   - 优化走线路径

**预期结果**：硬件整改带来根本性改善

## 五、结论模板

### 问题分析

#### 干扰源
- **模块**：LCD MIPI
- **噪声来源**：DSI Clock及数据线开关噪声
- **基频范围**：60-120MHz

#### 受扰体
- **频段**：GNSS L1 (1561-1606MHz)
- **敏感度要求**：-140 ~ -150dBm
- **当前恶化**：5-15dB

#### 耦合路径
- **类型**：辐射耦合
- **机制**：MIPI走线空间辐射耦合到GNSS天线

### 改善措施

#### 软件措施
1. 启用LCD MIPI展频功能（SSC）
2. 优化MIPI时钟频率规划
3. GPS定位时动态控制屏幕亮度

#### 硬件措施
1. 加强LCD FPC屏蔽层设计
2. 优化LCD屏蔽罩接地
3. 增加LCD与GNSS天线间距

#### 长期措施
1. 在GNSS LNA前端增加带通滤波器
2. 优化时钟频率规划避开敏感频段
3. 采用方向性更好的GNSS天线

## 六、典型案例

### 案例 1：旗舰手机GNSS L1受干扰
- **问题描述**：亮屏状态下GPS定位精度下降8dB
- **解决方案**：启用MIPI SSC + 优化时钟频率
- **改善效果**：灵敏度恢复至-148dBm

### 案例 2：平板设备定位漂移
- **问题描述**：室内定位漂移严重
- **解决方案**：加强LCD屏蔽 + 动态亮度控制
- **改善效果**：定位稳定性显著提升
