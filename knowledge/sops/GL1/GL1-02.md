# SOP-GL1-02：Camera MIPI → GNSS L1

**版本**：v2.0.0  
**日期**：2026-04-22  
**状态**：已完成

## 一、组合信息

### 干扰源
- **模块**：Camera System
- **噪声来源**：MIPI CSI Clock / Data、MCLK、AVDD 电源 SSN
- **基频范围**：MIPI CSI(200-800MHz)、MCLK(24-27MHz)、AVDD SSN(宽带噪声)

### 受扰体
- **频段**：GNSS L1
- **频率范围**：1575.42 MHz
- **敏感度要求**：-140 ~ -150 dBm

### 耦合路径
- **类型**：辐射耦合、传导耦合
- **机制**：MIPI CSI时钟谐波辐射 → 空间传播 → GNSS天线接收；AVDD SSN通过电源平面传导

---

## 二、理论预判

### 谐波命中计算

#### MCLK谐波分析
MCLK典型值为24MHz或27MHz：
- 24MHz × 65.64 = 1575.36MHz ✓ 命中GNSS L1
- 27MHz × 58.35 = 1575.45MHz ✓ 命中GNSS L1

#### MIPI CSI谐波分析
以典型配置计算：分辨率1920×1080，帧率30fps，10bit像素，4 Lane：
- MIPI Clock = 30 × 1920 × 1080 × 10 / 4 / 2 = 77.76MHz
- 77.76MHz × 20.27 = 1575.42MHz ✓ 命中GNSS L1

**结论**：Camera MCLK和MIPI CSI谐波均可能命中GNSS L1频段

### 设计审查必查项
1. **MIPI时钟规划**：检查是否预留SSC功能，避免基频谐波密集区
2. **MCLK滤波设计**：MCLK线上是否配置适当滤波电路
3. **Camera电源滤波**：AVDD/DVDD电源滤波是否充足
4. **FPC屏蔽设计**：Camera FPC屏蔽层完整性和接地设计
5. **天线布局**：GNSS天线与Camera模组距离是否足够

## 三、软件排查步骤

### 步骤 1：场景复现
**目标**：确认Camera相关干扰现象可复现

**操作**：
1. 进入测试场景：前摄/后摄预览或录像模式
2. 测量GNSS L1 C/N0值：记录基准值和恶化量
3. 记录干扰现象：描述恶化程度和稳定性

**预期结果**：Camera开启时GNSS L1灵敏度稳定恶化

### 步骤 2：干扰源确认
**目标**：确认干扰源为Camera相关模块

**操作**：
1. 关闭Camera应用：观察干扰是否消失
2. 切换前后摄像头：对比干扰差异
3. 调整分辨率/帧率：观察干扰变化规律
4. 对焦/闪光灯测试：验证辅助功能影响

**预期结果**：确认干扰源为Camera MIPI CSI或MCLK

### 步骤 3：频率验证
**目标**：验证干扰频率与理论预判一致

**操作**：
1. 读取当前MIPI Clock配置：通过log或配置读取
2. 读取MCLK频率：确认实际工作频率
3. 计算谐波命中：验证与1575.42MHz的关系
4. 频谱仪观察：确认干扰频谱特征

**预期结果**：频率关系与理论预判一致

### 步骤 4：软件规避尝试
**目标**：尝试软件措施改善干扰

**操作**：
1. 尝试MIPI SSC：
   - 开启SSC展频功能
   - 测量改善效果：记录dB改善
2. 尝试频率调整：
   - 调整MIPI Clock到非风险频率
   - 测量改善效果：记录dB改善
3. 尝试功能优化：
   - 降低帧率（30fps→24fps）
   - 减少Lane数（4 Lane→2 Lane）
   - 测量改善效果：记录dB改善

**预期结果**：记录各项软件措施的改善效果

## 四、硬件排查步骤

**触发条件**：软件措施无效或改善不足

### 步骤 1：路径确认
**目标**：确认耦合路径类型

**操作**：
1. 近场扫描：使用近场探头扫描Camera模组/FPC/B2B区域
2. 屏蔽测试：临时屏蔽FPC观察效果
3. 接地测试：改善接地观察效果
4. 电源测量：测量AVDD纹波噪声

**预期结果**：确认主要耦合路径为FPC辐射或电源传导

### 步骤 2：硬件整改验证
**目标**：验证硬件整改措施有效性

**操作**：
1. FPC屏蔽整改：
   - 导电布包裹FPC并良好接地
   - 测量改善效果：3-6 dB
2. MCLK滤波整改：
   - 串接电阻（22-100Ω）+ 并联电容（10-33pF）
   - 测量改善效果：1-3 dB
3. 电源滤波整改：
   - AVDD增加π型滤波电路
   - 测量改善效果：2-4 dB
4. 结构优化：
   - 天线拉远距离（如结构允许）
   - 贴吸波材吸收辐射

**预期结果**：硬件整改措施有效改善干扰

## 六、典型案例

### 案例 1：后摄预览GPS L1恶化5dB
- **问题描述**：后摄开启预览时，GPS L1 C/N0恶化5dB，定位漂移
- **解决方案**：开启MIPI SSC（调制深度2%，调制率30kHz），改善3dB
- **根本原因**：MIPI Clock 77.76MHz第20次谐波命中1575.42MHz

### 案例 2：前摄录像WiFi 2.4G干扰
- **问题描述**：前摄录像时WiFi吞吐量下降40%，RSSI恶化6dB
- **解决方案**：调整MIPI Clock从400MHz到375MHz，改善4dB
- **根本原因**：MCLK 24MHz第100次谐波命中2400MHz
