# SOP-GL1-04:PMIC → GNSS L1

**版本**:v0.9.0
**日期**:2026-05-06
**状态**:**方法论版(待现场复测)** — 从 placeholder v0.1 升级,基于 EMC 2024 C.3 案例反哺 + LLB-04 结构参照 + GL1-01 GPS 特别要求参照,**未经现场实测验证**

> **复测提醒**:PMIC → GPS 常涉及屏蔽罩设计级缺陷,本 SOP 强调"设计审查必查项";现场需结合 BOT 面 PMIC 布局 + 屏蔽罩设计验证。
>
> **与 GL1-03 的关系**:GL1-03 聚焦 DDR 作为干扰源;GL1-04 聚焦 PMIC 作为干扰源。二者可能共享同一案例(C.3 即如此),但"源归因"不同 → 整改路径不同(GL1-03 偏 DDR 频率 / 屏蔽,GL1-04 偏 PMIC 屏蔽罩设计 / 电源滤波)。

## 一、组合信息

### 干扰源
- **模块**:PMIC(Power Management IC,系统电源管理芯片)
- **代码**:PM
- **分类**:电源
- **噪声来源**:
  - **DCDC Buck 开关噪声**(典型基频 0.5-3 MHz,部分高频 Buck 可达 4-6 MHz)
  - **LDO 底噪**(宽带 — 影响接收机 NF)
  - **DCDC 开关瞬间尖峰**(负载跳变时产生的宽带高频能量)
  - **PFM / PWM 模式切换跳频噪声**(轻载 PFM 频率随负载浮动,频谱不稳定)
- **基频范围**:0.5-6 MHz(具体依 PMIC 型号和 Buck 档位)
- **典型干扰**:**高次谐波密集命中 L1 频段**(基频低,N 次谐波阶次高,谱线密);叠加宽带底噪抬高 NF

### 受扰体
- **频段**:GNSS L1
- **代码**:GL1
- **频率范围**:1561-1606 MHz(GPS L1 1575.42 / BDS B1I 1561.098 / GLONASS G1 ~1602 / Galileo E1 1575.42)
- **敏感度要求**:**-140 ~ -150 dBm**(**极度敏感** — 比 LTE 灵敏 45-55 dB,比 WiFi 灵敏 50-60 dB)
- **恶化阈值**:**3 dB 即严重**(GPS SOP 阈值应比 WiFi / LTE 更严,见 C.3 启示 1)

### 耦合路径
- **主要类型**:**辐射耦合(主)** — PMIC 屏蔽罩泄露 / 开窗 / 接地不良,噪声经 PCB 另一面 → GPS 天线
- **次要类型**:**传导耦合(次)** — 电源平面纹波经射频供电路径窜入 LNA
- **机制**:
  - 辐射路径(C.3 核心):BOT 面 PMIC 屏蔽罩顶部开窗 → 噪声泄漏到 PCB 另一面 → GPS 天线
  - 传导路径:PMIC 输出纹波 → VDD_RF / VDD_LNA → GPS 接收链路
  - 结构路径:PMIC 大电流引起地弹 → 中框接地参考偏移 → GPS 天线接地

### 矩阵元信息
- **优先级**:P1
- **典型恶化量**:3-8 dB(普通场景),设计级缺陷可达 3-6 dB 但持续存在无法软件规避
- **快速诊断提示**:**冷启动 TTFF 异常 + 弱信号场景定位失败**(地库 / 峡谷 / 室内)

## 二、理论预判

### 谐波命中计算

PMIC DCDC 基频 0.5-6 MHz,命中 L1(1561-1606 MHz)需要 260-3200 次谐波 — **阶次非常高,但 DCDC 开关波形非正弦,高次谐波衰减较慢,仍能显著抬高 L1 底噪**。

| DCDC 基频 | 谐波次数 | 命中频点 | 是否命中 L1(1561-1606) |
|---|:---:|---|:---:|
| 1.0 MHz | 1575 | 1575 MHz | ✓ GPS L1 中心 |
| 2.0 MHz | 780 | 1560 MHz | ✓ L1 低端边缘 |
| 2.0 MHz | 790 | 1580 MHz | ✓ L1 中段 |
| 3.0 MHz | 525 | 1575 MHz | ✓ GPS L1 中心 |
| 4.0 MHz | 400 | 1600 MHz | ✓ L1 高端 |
| 6.0 MHz | 267 | 1602 MHz | ✓ GLONASS G1 |

**关键区别于 LLB**:对 LTE LB(700 MHz)只需 175-700 次谐波即可命中;对 GPS L1 需要 260-3200 次,**单条谱线能量更弱**,但**密度更高(频谱内谱线数更多)+ 宽带底噪抬高 NF** 是主要危害机制,而非单条强谱线。

> **结论**:PMIC 对 GPS 的危害**以"宽带底噪抬升 NF"为主,高次谐波谱线为辅**;整改方向应偏向**封闭屏蔽 + 电源滤波带宽**,而非单纯避开某一频点。

### 屏蔽罩设计级缺陷专节(C.3 核心启示)

> **C.3 根因**:BOT 面 PMIC 屏蔽罩**顶部有开窗**(为其他工艺便利而开),噪声从开窗处辐射,通过 PCB 另一面耦合到 GPS 天线 → **属于设计级缺陷,非装配 / 物料问题,所以常规整改无效(42 天)**。

**C.3 提炼的三条设计级启示**(必须在本 SOP 二、四章节反复强调):

1. **"设计级开窗"是隐蔽缺陷** — 普通 SOP 的"屏蔽罩密封性检查"通常查装配,但**设计级开窗是"合规装配但设计本身不合规"**。必须在 PCB / 屏蔽罩设计 review 阶段就标注。

2. **BOT 面 PMIC ≠ TOP 面 PMIC** — BOT 面屏蔽罩一旦有开窗,噪声容易绕过 PCB 到达 TOP 面天线;TOP / BOT 对称设计时 GPS 位置应有专项评估。

3. **GPS 3 dB 不可接受** — GPS 敏感度 -140 ~ -150 dBm,3 dB 恶化显著影响 TTFF / 弱信号定位 / 峡谷地库场景可用性。**GPS SOP 阈值比 LTE / WiFi 更严**。

### 设计审查必查项

1. **屏蔽罩所有开窗**:**必须标注功能必要性 + RF 影响评估**(C.3 核心教训 —— 开窗不是无代价的,必须在设计 review 时明示)
2. **PMIC 物理位置 vs GPS 天线距离**:BOT 面 PMIC 与 TOP 面 GPS 天线是否"对位"
3. **BOT 面 vs TOP 面布局对称性**:BOT 面屏蔽罩开窗位置是否刚好投影到 TOP 面天线
4. **DCDC 频率规划**:是否在 GPS L1 附近谐波密集,SSC / dithering 是否启用
5. **PMIC 接地点数量与位置**:屏蔽罩接地点密度(影响高频泄漏)
6. **电源去耦完整性**:PMIC 输出各路供电的 LC 滤波,特别是 VDD_RF / VDD_LNA
7. **积水铜箔 / 封闭屏蔽**:是否采用完全封闭的屏蔽形态(C.3 最终方案)
8. **大电流环路面积**:Buck 输入 / 输出环路面积(越小辐射越弱)

## 三、软件排查步骤

> **前置说明**:**PMIC 设计问题通常软件无解**。本章节步骤仍需执行,目的是**排除软件可控因素,快速将问题移交硬件 / 结构团队**,避免无谓的软件调参耗时。

### 步骤 1:场景复现

**目标**:确认 PMIC 相关 GPS Desense 可复现,且受扰为 GPS 敏感场景

**操作**:
1. **弱信号环境测试**(同 GL1-03 —— 强调 GPS 特别要求):
   - 室内 / 地库 / 峡谷等弱信号场景
   - 模拟器输入信号:-130 / -135 / -140 dBm 三档
2. 读取 C/N0、TTFF、定位成功率
3. 对比基线(PMIC 负载变化小的场景)和加压场景(大电流负载)

**预期结果**:PMIC 高负载(大电流)场景下 C/N0 下降 3-6 dB,TTFF 明显变长

### 步骤 2:干扰源确认

**目标**:确认干扰源为 PMIC(而非 DDR / CPU / Camera 等其他模块)

**操作**:
1. **关不同 DCDC 分支观察改善**(如可配置):
   - 单独关闭 BUCK1 / BUCK2 / BUCK3 / ...,对比 C/N0 变化
   - 找到贡献最大的 Buck 分支
2. **负载变化测试**:手动切换系统负载档位(idle → 轻载 → 重载),观察干扰与 PMIC 电流正相关性
3. **外部供电测试**(如硬件支持):绕过 PMIC 直接外部供电,排除充电回路
4. **模块关断对照**:依次关闭 DDR / Camera / LCD,若 GPS 仍恶化 → 指向 PMIC

**预期结果**:干扰与 PMIC 工作状态(特别是大电流 Buck 分支)强相关

### 步骤 2.5:DCDC 工作模式排查

**目标**:识别 PFM / PWM 模式切换或负载突变引起的间歇性恶化

**操作**:
1. **固定 PWM 模式测试**:强制 PMIC 主要 Buck 工作在 PWM(固定频率),观察干扰稳定性
2. **固定 PFM 模式测试**:强制 PFM(频率随负载浮动),观察频谱是否抖动
3. **负载电流记录**:在干扰最严重时记录 PMIC 主要供电轨的电流,判断是否触发模式切换
4. **DCDC 频率 sweep**(若 PMIC 支持):扫不同开关频率,找改善点

**预期结果**:
- 若固定 PWM 改善明显 → PFM 切换跳频引入宽带噪声 → 软件可规避
- 若两种模式都严重 → 屏蔽 / 滤波级问题 → 进入硬件路径

### 步骤 2.6:多源叠加排查(C.3 典型)

**触发条件**:步骤 2 无法定位到单一 PMIC 分支,或排除 PMIC 后仍有残余恶化

**背景**:C.3 案例是 **DDR + PMIC + SHIELD_LEAK 三源叠加**(GL1-03 + GL1-04 + NORMAL-07 同时命中)。

**操作**:按 [`_template.md` 多源叠加排查法](../_template.md):
1. **候选源枚举**:
   - H1:PMIC DCDC 开关噪声(本 SOP 焦点)
   - H2:DDR 时钟 / 数据噪声(转 GL1-03 排查)
   - H3:屏蔽罩设计级泄漏(转 NORMAL-07 排查)
   - H4:电源平面耦合(传导路径)
2. **各源单独贡献测量**:依次屏蔽 / 关断,分别测 ΔC/N0
3. **累加验证**:ΣΔ 与总 Desense 对比,找出**主源 + 次源 + 放大器**

**C.3 现场结论**:PMIC 是**次源(1 dB 量级)**,但**屏蔽罩顶部开窗是放大器**(让 DDR + PMIC 宽带底噪直穿到天线),设计级整改才从根本解决。

### 步骤 3:频率验证

**目标**:频谱仪定位 DCDC 谐波 spur 和宽带底噪

**操作**:
1. 频谱仪设 RBW = 100 kHz,扫描 1561-1606 MHz
2. 在 PMIC 大电流负载场景下测宽带底噪抬升量(相对空闲基线)
3. 查找等间距谱线(间距 = DCDC 基频)
4. 对比关 PMIC(或关某 Buck)前后的频谱差异

**预期结果**:
- 若能看到等间距 spur → DCDC 谐波主导
- 若仅看到宽带底噪抬升无明显谱线 → LDO 底噪 / 多 Buck 谐波叠加 / 屏蔽不良

### 步骤 4:软件规避尝试

**目标**:尝试软件级改善(通常改善有限,用于争取硬件整改时间)

**操作**:
1. **DCDC 模式锁定**:强制 PWM 固定频率,避免 PFM 跳频(改善 1-3 dB)
2. **负载平衡**:拉平大电流瞬态,减少开关瞬间尖峰(改善 0.5-2 dB)
3. **DCDC 频率微调**(若支持):偏移 5-10% 规避谱线密集区(改善 1-2 dB)
4. **GPS 工作时降低系统负载策略**(应用级):定位关键时刻限制 CPU / DDR 流量,间接降低 PMIC 输出电流(改善 1-3 dB,用户体验代价需评估)

**预期结果**:软件合计改善 1-4 dB;若仍不达标 → 硬件路径

## 四、硬件排查步骤

> **重要**:**PMIC → GPS 问题,硬件才是主路径**(因 PMIC 常为设计级缺陷,软件仅缓解)。本章节重点在 Step 1 近场定位 + Step 3 屏蔽罩设计改版。

### 步骤 1:近场定位 — BOT 面 PMIC 屏蔽罩周围

**目标**:精确定位 PMIC 屏蔽罩上的泄漏点

**操作**:
1. **BOT 面近场扫描重点位置**:
   - 屏蔽罩**顶部开窗**(C.3 案例位置 —— 必查)
   - 屏蔽罩四周焊点 / 接地指
   - 屏蔽罩拼缝 / 贴合面
2. **对比扫描**:
   - PMIC 屏蔽罩完整 vs 开窗位置覆盖铜箔
   - 记录各位置相对辐射强度
3. **TOP 面对应位置扫描**:检查"穿透"效应 — BOT 面开窗的噪声是否在 TOP 面 GPS 天线附近复现
4. **天线隔离度测试**:临时拆 GPS 天线,外接到远离 PMIC 的位置,对比改善

**预期结果**:定位到屏蔽罩上具体的"热点",通常即开窗位置;TOP 面同位置场强高

**C.3 实战参考**:近场扫描明确显示 **BOT 面 PMIC 屏蔽罩顶部开窗是最强辐射源**,TOP 面 GPS 天线正好在其投影区。

### 步骤 2:屏蔽罩密封加强(短期整改)

**目标**:不动设计 PCB 的前提下用物料封堵开窗

**操作**:
1. 开窗处贴**铜箔 + 良好接地**(至少两侧接地)
2. **导电泡棉**填充屏蔽罩与 PCB / 中框缝隙
3. 加强屏蔽罩边缘焊点 / 点胶
4. 测改善量

**预期结果**:可改善 2-4 dB,但**不能完全解决** —— 铜箔接地电感 + 工艺一致性问题,不是长期方案

> **C.3 教训**:**普通整改 > 3 周无进展 → 强制升级到设计级 review**(时间护栏:30 天)。常规加铜箔 / 加胶 / 加接地的迭代在 C.3 耗时 30 天仍未达标 → 走 Step 3。

### 步骤 3:屏蔽罩设计改版(长期方案,C.3 最终方案)

**目标**:从设计层面消除泄漏源

**操作**:
1. **取消 PMIC 屏蔽罩顶部开窗**:与结构 / 工艺团队对齐开窗的原功能,寻找替代方案
2. **切换积水铜箔**(C.3 方案):完全封闭式屏蔽,不留任何设计级开口
3. **增加屏蔽罩接地指密度**:高频泄漏衰减 6-10 dB/倍接地点数
4. **BOT / TOP 布局 review**:若 PMIC 与 GPS 天线"对位",在 PCB 改版时考虑偏移 PMIC / GPS 位置

**预期结果**:**彻底消除设计级泄漏**,改善 3-6 dB;GPS 恢复至 -148 dBm 量级

**代价**:设计级改版需 PCB 改版 + 屏蔽罩重新开模,**耗时 40+ 天(C.3 实际 42 天)**,成本最高但一劳永逸。

### 步骤 4:电源去耦改版(与屏蔽罩并行)

**目标**:降低 PMIC 输出纹波,对传导路径整改

**操作**:
1. **VDD_RF / VDD_LNA 追加 LC 滤波**:π 型网络(电感 + 两端电容)
2. **BOT 面电源滤波电容追加**:PMIC 输出端靠近 IC 位置加 0.1 μF + 10 nF 小电容
3. **DCDC 输出环路面积压缩**:Buck 输出电感与输出电容走线就近
4. **PMIC 接地过孔增密**:减小地回流阻抗

**整改点改善 dB 表**:

| 整改点 | 措施 | 预期改善 | 主要针对 |
|---|---|:---:|---|
| 屏蔽罩顶部开窗 | 铜箔封堵 + 良好接地 | 2-4 dB | 辐射(短期) |
| 屏蔽罩设计改版 | 取消开窗 / 积水铜箔 | 3-6 dB | 辐射(根本) |
| BOT 面电源滤波 | 追加 LC 滤波 + 小容值去耦 | 1-3 dB | 传导 |
| DCDC 环路压缩 | Buck 走线优化 | 1-2 dB | 辐射近场 |
| PMIC 接地密度 | 增加接地过孔 / 接地指 | 1-2 dB | 辐射+地弹 |
| BOT/TOP 布局偏移 | 避免 PMIC 与 GPS 天线对位 | 2-4 dB | 辐射穿透 |

## 六、典型案例

### 案例 1:O11U GPS L1 DDR Desense 3 dB(PMIC 屏蔽罩顶部开窗,设计级缺陷)

**聚焦角度**:**PMIC 作为干扰源**(与 GL1-03 共享该案例,但 GL1-03 从 DDR 角度切入)。

- **机型 / 阶段**:O11U / P0.1
- **现象**:GPS L1 DDR 场景 Desense **3 dB**(1561-1606 MHz)—— 数字小但 GPS 敏感度 -140 dBm,足以影响 TTFF / 地库峡谷场景
- **PMIC 源贡献识别**:
  - 步骤 2 关 BUCK 分支测试 → PMIC 贡献约 1 dB(次源,但非主导)
  - 步骤 2.6 多源叠加 → PMIC + DDR 宽带底噪经 BOT 面 PMIC 屏蔽罩**顶部开窗**泄漏放大
- **根因(设计级)**:BOT 面 PMIC 屏蔽罩**顶部开窗**(为其他工艺便利),噪声经 PCB 另一面耦合至 TOP 面 GPS 天线
- **普通整改 30 天无效**:屏蔽罩加胶 / 接地 / 铜箔迭代均未达标
- **设计级最终方案(42 天闭环)**:**取消 PMIC 屏蔽罩顶部开窗,切换积水铜箔**(完全封闭屏蔽)
- **收敛**:GPS L1 恶化回到限值内

**三条启示(与 C.3 案例保持一致)**:
1. GPS 3 dB ≠ WiFi 3 dB → GPS SOP 阈值应更严
2. "设计级开窗"是"合规装配但设计不合规",必须在设计 review 阶段捕捉
3. 多源叠加需矩阵综合命中(本案例触发 GL1-03 + GL1-04 + NORMAL-07 三个 SOP)
4. **时间护栏**:普通整改 > 3 周无进展 → 强制升级到设计级 review

**参考**:[O11U-GL1-shield-aperture.md](../../cases/O11U-GL1-shield-aperture.md)

## 八、附录

### 术语表
- **PMIC**:Power Management IC,电源管理芯片
- **DCDC**:Direct Current to Direct Current,开关型直流转换器
- **Buck**:降压型 DCDC 转换器
- **LDO**:Low Dropout Regulator,低压差线性稳压器
- **PWM**:Pulse Width Modulation,脉宽调制 — DCDC 重载时固定频率工作模式
- **PFM**:Pulse Frequency Modulation,脉频调制 — DCDC 轻载时变频工作模式(频谱不稳定)
- **积水铜箔**:完全封闭的铜箔屏蔽形态,不留任何设计级开窗(C.3 最终方案)
- **TTFF**:Time To First Fix,GPS 冷启动首次定位时间
- **C/N0**:Carrier to Noise Density Ratio,载噪比(GPS 信号质量指标,dB-Hz)
- **Desense**:De-sensitization,灵敏度恶化

完整术语见 [knowledge/glossary.md](../../glossary.md)。
