# SOP-W24-08:NFC → WiFi 2.4G

**版本**:v0.9.0
**日期**:2026-05-06
**状态**:**方法论版(待现场复测)** — 从 placeholder v0.1 升级,基于 EMC 2024 B.2 案例反哺 + W24-01 结构参照,**未经现场实测验证**

> **复测提醒**:NFC 高次谐波命中 2.4G 是共存类耦合,本 SOP 的谐波表和整改参数均为方法论推导,现场请按具体机型的 NFC 电路布局验证。

---

## 一、组合信息

### 干扰源
- **模块**:NFC(Near Field Communication)
- **代码**:NF
- **分类**:**共存**(与 WiFi 2.4G 为物理近场共存的独立功能模块)
- **基频范围**:13.56 MHz(ISO 14443 / NFC Forum 标准载波)
- **噪声来源**:
  - NFC 载波 13.56 MHz **高次谐波**(约 177 次 ≈ 2400 MHz,命中 WiFi 2.4G 低端)
  - NFC 匹配电路 / 驱动电路开关噪声
  - NFC 天线 / 射频通路共存辐射
- **典型干扰**:**窄带 + 场景激活型** —— NFC 只在被激活(Display/Touch/支付)时工作,工作期间高次谐波密集覆盖 2.4G 附近

### 受扰体
- **频段**:WiFi 2.4G
- **代码**:W24
- **频率范围**:2412-2484 MHz
- **敏感度要求**:-82 ~ -90 dBm

### 耦合路径
- **主要类型**:**传导 + 辐射混合**
- **机制**:
  - **传导路径**:NFC 驱动电流经共用电源 / 地平面耦合到 WiFi 前端
  - **辐射路径**:NFC 天线 / 匹配电路高次谐波直接耦合到 WiFi 天线(近距共存时)
  - **射频通路耦合**:NFC 与 WiFi 射频信号路径布线交叉 / 并行,导致谐波串扰

### 矩阵元信息
- **优先级**:P1 ⭐ 高优先级
- **典型恶化量**:10-20 dB(源案例 O2 B.2:**20 dB**)
- **快速诊断提示**:**关闭 NFC 功能验证**(黄金动作,5 分钟内定位)
- **场景特征**:**Display/Touch on** 场景触发(NFC 被业务层激活)

## 二、理论预判

### 谐波命中计算

NFC 基频 13.56 MHz,命中 WiFi 2.4G(2412-2484 MHz)的谐波次数约为 N=178~183:

| 谐波次数 N | 13.56 × N(MHz) | 是否命中 2.4G | 对应信道 |
|:---:|:---:|:---:|---|
| 177 | 2400.12 | ✗(刚低于 2412) | — |
| 178 | 2413.68 | ✓ 命中 | ch1 附近 |
| 179 | 2427.24 | ✓ 命中 | ch3-4 |
| 180 | 2440.80 | ✓ 命中 | ch6 附近 |
| 181 | 2454.36 | ✓ 命中 | ch8-9 |
| 182 | 2467.92 | ✓ 命中 | ch11-12 |
| 183 | 2481.48 | ✓ 命中(低端) | ch13-14 边界 |

**结论**:
- 13.56 MHz 的 178~183 次谐波**几乎均匀覆盖整个 WiFi 2.4G 频段**
- 高次谐波能量虽比基频弱,但因 NFC 驱动电路非线性较强,177+ 次谐波仍可能有可观幅度
- 单机型实测应用频谱仪确认主导谐波次数,避免只看 177 次("最接近 2400 MHz"的想当然假设)

> **源案例 B.2 的经验**:33 天耗时的核心教训是"假设锁死"—— 团队默认 Display 场景恶化 = LCD MIPI,没把 NFC(Display 场景常态工作)作为平行假设。本 SOP 的存在本身就是修正这一盲点。

### 设计审查必查项

1. **NFC 天线与 WiFi 天线物理距离 / 隔离度**
   - NFC 天线常贴电池背面或后壳内侧,WiFi 天线常在顶部 / 底部
   - 近距共存时隔离度应 ≥ 20 dB(目标值,需结构+射频联合评估)
2. **NFC 匹配电路滤波**
   - NFC 控制器输出端的 EMI 滤波(LC 网络,低通截止应充分抑制 > 500 MHz 高次谐波)
   - 匹配电路到天线之间的走线是否有旁路电容
3. **射频通路层叠 / 布线规划**
   - NFC 走线与 WiFi 2.4G 射频走线的并行长度 / 交叉次数
   - 两者是否共用 RF Ground,是否有完整的地回流路径
4. **共用电源 / 地平面**
   - NFC 驱动电源是否独立,或与 WiFi / 其他 RF 共轨
   - 地平面分割与桥接点(NFC 大电流驱动时的地弹点)
5. **NFC 工作模式规划**
   - 读卡器 / 卡模拟 / P2P 模式的射频占空比和峰值功率
   - 业务层是否在 WiFi 高敏感场景强制关闭 NFC(LPM / 时分复用策略)
6. **源案例反哺**:O2 B.2 最终方案为 **PCB 改版 + 射频通路滤波网络**,说明布局和滤波是本类问题的决战点

## 三、软件排查步骤

### 步骤 1:场景复现

**目标**:确认 Display/Touch on 场景下 WiFi 2.4G Desense 可复现

**操作**:
1. 空载测量 WiFi 2.4G 各信道平坦度 → 基线
2. 点亮屏幕(Display on),进入 Touch 交互状态(NFC 通常随屏激活)
3. 测量 Display/Touch on 场景 WiFi 2.4G 各信道灵敏度
4. 差值 = 场景 Desense

**预期结果**:Display/Touch on 时 WiFi 2.4G 恶化 10-20 dB(B.2 源案例:20 dB)

### 步骤 2:干扰源确认(**黄金动作**)

**目标**:通过关闭 NFC 快速排除 / 确认 NFC 为主要干扰源

**操作**:
1. **关闭 NFC 功能**(设置菜单或 ADB `svc nfc disable`)
2. 保持 Display/Touch on 状态不变,重测 2.4G Desense
3. **判定**:
   - 干扰消失 / 大幅改善(≥ 5 dB) → **H2:NFC 共存干扰命中**,进入步骤 2.5
   - 改善不明显(< 2 dB) → NFC 不是主源,回到 W24-01(LCD MIPI)等其他假设

**预期结果**:一次开关动作,5 分钟内给出 NFC 是否为主源的判决

> **关键教训**(源案例 B.2):团队在 H1=LCD MIPI 假设上消耗了 33 天,若第一天就执行本步骤,诊断周期可缩短到 1 天量级。**"关闭 NFC 验证"应作为 Display 场景任意 Desense 排查的 Day-1 动作**。

### 步骤 2.5:NFC 工作模式排查

**目标**:定位哪种 NFC 工作模式贡献最大干扰

**操作**(在 NFC on 前提下,逐模式激活):
1. **读卡器模式(Reader/Writer)**:NFC 主动发射载波,持续辐射
2. **卡模拟模式(Card Emulation,HCE)**:被动响应为主,载波间歇
3. **P2P 模式**:双向数据交换,载波活跃
4. 记录各模式下 2.4G Desense 值

**预期结果**:识别出主导模式(通常是读卡器 / P2P 持续发射载波场景最严重)

### 步骤 2.6:多源叠加排查

**触发条件**:步骤 2(关 NFC)改善部分但残余恶化仍 > 内部限值(> 4 dB)

**操作**:按 [`_template.md` 步骤 2.6](../_template.md) 多源叠加排查法,候选源枚举:
- H1:NFC(已在步骤 2 确认为主源)
- H2:LCD MIPI(Display 场景另一主源,见 W24-01)
- H3:Touch IC(电容屏驱动,与 NFC 场景共激活)
- H4:Display 背光 Boost / PMIC 屏电压轨

逐一关闭各源(或分别测试组合),记录 ΔdB,输出叠加模型。

### 步骤 3:频率验证

**目标**:验证 NFC 载波高次谐波确实命中 2.4G

**操作**:
1. 频谱仪(或手机内置频谱工具)在 2412-2484 MHz 范围扫描,NFC on 场景
2. 识别离散谱线位置,与 13.56 MHz × 178~183 理论值比对
3. 关闭 NFC,谱线应消失
4. 记录主导谐波次数和幅度

**预期结果**:谱线出现在 178~183 次谐波预测位置,关 NFC 即消失,闭环证明 NFC 谐波命中

### 步骤 4:软件规避尝试

**目标**:软件优先措施评估改善量

**操作**:
1. **NFC on/off 时分复用**:业务层策略 —— 在 WiFi 高流量 / 高敏感操作时自动暂停 NFC 扫描
2. **NFC 功率调整**:若 NFC 栈支持,降低发射功率(代价:读卡距离缩短)
3. **NFC 低功耗模式(LPM)**:屏亮但 NFC 无业务时进入 LPM,大幅降低载波 duty cycle
4. **WiFi 信道避让**:若主导谐波集中在少数信道(如 ch6),业务层避开(权宜方案)

**预期结果**:软件措施典型改善 2-5 dB;**共存类干扰软件很难彻底解决,硬件整改通常是最终方案**(B.2 源案例即为此)

## 四、硬件排查步骤

**触发条件**:软件措施改善不足(< 设计限值),或需在设计阶段规避

### 步骤 1:路径确认(近场扫描)

**目标**:定位 NFC 干扰的主要耦合点

**操作**:
1. **近场扫描**:近场探头扫描 NFC 天线边缘 / 匹配电路 / NFC 控制器输出端
2. **辐射路径验证**:在 NFC 天线与 WiFi 天线之间加临时屏蔽(铜箔 / 吸波材料),看改善
3. **传导路径验证**:测 NFC 驱动电源纹波、地平面在 2.4G 频段的耦合电压
4. **射频通路共存扫描**:扫 NFC 走线与 WiFi 走线交叉 / 并行段

**预期结果**:定位主导路径(辐射 vs 传导 vs 射频通路串扰)

### 步骤 2:硬件整改验证

| 整改点 | 措施 | 预期改善 |
|---|---|:---:|
| NFC 天线屏蔽 | 加铁氧体磁片 / 局部吸波材料 | 3-6 dB |
| NFC 匹配电路滤波 | LC 低通滤波加强,抑制 > 500 MHz 谐波 | 3-8 dB |
| **射频通路滤波网络**(B.2 方案) | WiFi 2.4G RF 通路前端增加滤波,抑制 NFC 谐波进入 WiFi 前端 | 8-15 dB |
| NFC / WiFi 天线布局 | 增加物理距离,调整天线方向 | 2-5 dB |
| 地平面分割 / 桥接 | NFC 地独立,仅在单点与 RF 地汇合 | 2-4 dB |
| NFC 电源去耦 | 加大容值电容 / 串磁珠 | 1-3 dB |
| **PCB 改版**(源案例最终方案) | 综合布局 + 滤波 + 地平面优化的整体改版 | 总改善 ≥ 15 dB |

**预期结果**:综合改善到内部限值(≤ 4 dB)

## 六、典型案例

### 案例 1:O2 WiFi 2.4G Display Fail 20 dB — NFC 谐波干扰(EMC 2024 B.2)

**本 SOP 首源案例**,详见 [O2-NFC-W24.md](../../cases/O2-NFC-W24.md)。

**核心要点**:
- **机型**:O2,阶段 P1,持续 **33 天**
- **现象**:Display/Touch on 场景 WiFi 2.4G Desense **Fail 20 dB**
- **根因**:NFC 载波 13.56 MHz × 177 ≈ 2400 MHz 高次谐波经射频通路耦合到 WiFi 前端
- **最终方案**:**PCB 改版 + 射频通路滤波网络**(硬件整改)
- **反哺产物**:matrix.yaml v2.1.0 新增 NFC 源 / 共存分类;本 SOP(W24-08)建立

**教训(33 天耗时反思)**:
1. **假设锁死是最大陷阱**:团队默认"Display 场景恶化 = LCD MIPI",把 NFC 排除在候选假设之外,消耗 ~33 天走弯路
2. **平行假设原则**:`/diagnose` Step 4 决策树应同时输出多个候选,而非锁定 H1;若 H1 3~5 天无进展应强制回到 Step 3 重新枚举
3. **共存类源的盲区**:传统 matrix 按"时钟/电源/射频/显示/存储/摄像"分类,**缺少"共存类"**。场景激活的"非场景本身"功能(NFC / Touch IC / UWB / 蓝牙)是常见遗漏点
4. **黄金动作的价值**:"关闭 NFC 验证"本质只需 5 分钟,如果作为 Day-1 动作,诊断周期可从 33 天压缩到 1 天
5. **软件优先 vs 软件无效**:共存类谐波干扰,软件能做的极少(时分复用、LPM),硬件整改(滤波 / 布局)才是决战点

## 八、附录

### 术语表

- **NFC**:Near Field Communication,近场通信,基于 13.56 MHz 载波的短距无线通信
- **ISO 14443**:NFC 卡模拟 / 读卡器模式遵循的主要标准(A/B 型)
- **NFC Forum**:NFC 行业标准组织,定义 P2P / Reader/Writer / Card Emulation 三大模式
- **HCE**:Host Card Emulation,主机卡模拟,手机无 SE 也可模拟卡
- **LPM**:Low Power Mode,NFC 的低功耗模式(屏亮但无业务时载波占空比降低)
- **共存(Coexistence)**:多个独立 RF 模块在同一设备内物理近场共存,典型包括 NFC / UWB / 蓝牙 / WiFi
- **高次谐波**:基频整数倍,N > 10 称高次,NFC 命中 2.4G 需 N ≈ 177~183 超高次

完整术语见 [knowledge/glossary.md](../../glossary.md)。
