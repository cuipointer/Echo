# SOP-W24-02：Camera System → WiFi 2.4G

**版本**：v2.1.0  
**日期**：2026-04-24  
**状态**：已完成

---

## 一、组合信息

### 干扰源
- **模块**：Camera System
- **噪声来源**：MIPI CSI Clock / Data、MCLK、AVDD 电源 SSN、**OIS/AF 驱动 IC**
- **基频范围**：MIPI CSI(200-800MHz)、MCLK(24-27MHz)、AVDD SSN(宽带噪声)、OIS/AF Driver(宽带 EMI)

### 受扰体
- **频段**：WiFi 2.4G
- **频率范围**：2400-2483.5 MHz
- **敏感度要求**：-65 ~ -75 dBm（接收灵敏度）

### 耦合路径
- **类型**：辐射耦合、传导耦合
- **机制**：MIPI CSI时钟谐波辐射 → 空间传播 → WiFi天线接收；电源噪声通过共模传导

---

## 二、理论预判

### 谐波命中计算

#### MCLK谐波分析
MCLK典型值为24MHz或27MHz：
- 24MHz × 100 = 2400MHz ✓ 命中WiFi 2.4G低端
- 24MHz × 103.5 = 2484MHz ✓ 命中WiFi 2.4G高端
- 27MHz × 88.9 = 2400.3MHz ✓ 命中WiFi 2.4G低端

#### MIPI CSI谐波分析
以典型配置计算：分辨率1920×1080，帧率30fps，10bit像素，4 Lane：
- MIPI Clock = 30 × 1920 × 1080 × 10 / 4 / 2 = 77.76MHz
- 77.76MHz × 30.9 = 2400MHz ✓ 命中WiFi 2.4G
- 77.76MHz × 32 = 2488.32MHz ✓ 接近WiFi 2.4G高端

**结论**：Camera MCLK和MIPI CSI谐波均可能命中WiFi 2.4G频段

### 设计审查必查项
1. **MIPI时钟规划**：避免基频谐波密集落在2400-2483.5MHz
2. **MCLK频率选择**：优先选择非100整数倍的频率（如19.2MHz）
3. **Camera电源滤波**：AVDD/DVDD电源滤波网络设计
4. **FPC屏蔽完整性**：Camera FPC全程屏蔽和多点接地
5. **WiFi天线布局**：天线与Camera模组最小距离要求
6. **共模滤波设计**：电源接口共模滤波措施
7. **OIS/AF Driver IC 选型**：评估驱动 IC 的 EMI 辐射特性，优选低 EMI 方案
8. **OIS Driver IC 屏蔽**：驱动 IC 区域是否有局部屏蔽设计

## 三、软件排查步骤

### 步骤 1：场景复现
**目标**：确认Camera相关干扰现象可复现

**操作**：
1. 进入测试场景：前摄/后摄预览或录像模式
2. 测量WiFi性能：记录吞吐量、RSSI、PER等指标
3. 扫描各信道：检查1/6/11信道干扰差异
4. 记录干扰现象：描述恶化程度和稳定性

**预期结果**：Camera开启时WiFi 2.4G性能稳定恶化

### 步骤 2：干扰源确认
**目标**：确认干扰源为Camera相关模块

**操作**：
1. 关闭Camera应用：观察干扰是否消失
2. 切换前后摄像头：对比干扰差异
3. 调整分辨率/帧率：观察干扰变化规律
4. 对焦/闪光灯测试：验证辅助功能影响

**预期结果**：确认干扰源为Camera相关模块，并定位到具体模组（前摄/后摄/特定镜头）

### 步骤 2.5：模组子功能逐项排查
**目标**：定位到具体模组后，逐一排查模组内各子功能的干扰贡献

> **重要**：此步骤为零成本软件操作，必须在进入频率验证（步骤3）之前完成。
> 遗漏此步骤可能导致非时钟类干扰源（如 OIS/AF 驱动）被延迟发现。

**操作**：
1. **关闭 OIS**：软件关闭光学防抖，测量 Desense 变化
2. **锁定 AF**：固定焦距（关闭自动对焦），测量 Desense 变化
3. **关闭闪光灯**：确保 Flash LED 关闭，测量 Desense 变化
4. **纯上电不预览**：仅给模组供电但不开启 MIPI 传输，测量 Desense 变化
5. **切换分辨率/帧率**：观察干扰是否随 MIPI 配置变化

**判定逻辑**：
| 测试结果 | 干扰源方向 | 下一步 |
|----------|-----------|--------|
| 关闭 OIS 改善 | OIS Driver IC | 进入 OIS 专项排查（步骤 4B） |
| 锁定 AF 改善 | AF VCM 驱动 | 排查 VCM 驱动电路 |
| 关闭闪光灯改善 | Flash LED 驱动 | 排查 Flash 驱动电路 |
| 纯上电即有干扰 | 电源 SSN / 模组本身 | 进入电源排查 |
| 切换分辨率有变化 | MIPI Clock | 进入步骤 3（频率验证） |
| 以上均无变化 | MCLK 或固定时钟 | 进入步骤 3（频率验证） |

**预期结果**：明确干扰源子类别，为后续排查指明方向

### 步骤 3：频率验证
**目标**：验证干扰频率与理论预判一致

**操作**：
1. 读取当前MIPI Clock配置：通过log或配置读取
2. 读取MCLK频率：确认实际工作频率
3. 计算谐波命中：验证与2400-2483.5MHz的关系
4. 频谱仪观察：确认干扰频谱特征和信道分布

**预期结果**：频率关系与理论预判一致，干扰集中在特定信道

### 步骤 4：软件规避尝试
**目标**：尝试软件措施改善干扰

**操作**：
1. 尝试MIPI SSC：
   - 开启SSC展频功能（调制深度1-2%）
   - 测量改善效果：记录吞吐量提升和RSSI改善
2. 尝试频率调整：
   - 调整MIPI Clock到非风险频率
   - 测量改善效果：记录各信道性能恢复
3. 尝试功能优化：
   - 降低帧率（30fps→24fps或15fps）
   - 减少Lane数（4 Lane→2 Lane）
   - 测量改善效果：记录性能改善

**预期结果**：WiFi吞吐量恢复，RSSI改善3-6dB

### 步骤 4B：OIS/AF 驱动专项软件规避
**触发条件**：步骤 2.5 确认干扰源为 OIS 或 AF 驱动

**操作**：
1. 调整 OIS PWM 驱动频率：如 Driver IC 支持可配置频率，尝试不同档位
2. 切换 OIS 工作模式：低功耗模式 / 降频模式 / 静态保持模式
3. 降低 AF 驱动电流：减小 VCM 驱动幅度
4. 测量各配置下的 Desense 变化

**预期结果**：找到干扰最小的 OIS/AF 工作配置，Desense 改善 2-4dB

## 四、硬件排查步骤

**触发条件**：软件措施无效或改善不足

### 步骤 1：路径确认
**目标**：确认耦合路径类型

**操作**：
1. 近场扫描：使用近场探头扫描Camera模组/FPC/B2B区域
2. 屏蔽测试：临时屏蔽FPC观察WiFi性能恢复
3. 电源测量：测量AVDD纹波和共模噪声
4. 天线隔离测试：临时外接天线验证布局影响

**预期结果**：确认主要耦合路径和干扰强度分布

### 步骤 2：硬件整改验证
**目标**：验证硬件整改措施有效性

**操作**：
1. FPC屏蔽整改：
   - 导电布包裹FPC并多点接地
   - 测量改善效果：吞吐量提升20-50%
2. MCLK滤波整改：
   - 串接电阻（33-100Ω）+ 并联电容（15-47pF）
   - 测量改善效果：RSSI改善2-4dB
3. 电源滤波整改：
   - AVDD增加π型滤波（10μF+100nF）
   - 添加共模滤波器
   - 测量改善效果：宽带噪声改善3-5dB
4. 结构优化：
   - WiFi天线位置优化（如可能）
   - 贴吸波材在Camera区域
5. OIS/AF Driver IC 整改：
   - Driver IC 局部屏蔽罩：在 IC 上方加小型金属屏蔽盖
   - Driver IC 周围加地孔隔离：增强 PCB 层面屏蔽
   - 驱动线串接磁珠/电阻：抑制驱动线高频辐射
   - 测量改善效果：Desense 改善 4-7dB

**预期结果**：WiFi性能基本恢复，满足商用要求

## 六、典型案例

### 案例 1：前摄预览WiFi吞吐量下降40%
- **问题描述**：前摄开启预览时，WiFi 2.4G吞吐量从200Mbps下降到120Mbps
- **解决方案**：调整MIPI Clock从400MHz到375MHz，吞吐量恢复到190Mbps
- **根本原因**：MCLK 24MHz第100次谐波2400MHz直接命中WiFi频段

### 案例 2：后摄录像WiFi信道6干扰严重
- **问题描述**：后摄录像时WiFi信道6 RSSI恶化8dB，其他信道影响较小
- **解决方案**：开启MIPI SSC（调制深度2%），各信道RSSI平均改善4dB
- **根本原因**：MIPI Clock 81MHz第29.6次谐波命中2437MHz（信道6中心）

### 案例 3：AS2 后摄Wide预览WiFi 2.4G全频段4~7dB Desense
- **问题描述**：AS2机器RC场景，后摄Wide相机预览时WiFi 2.4G全频段(2412-2472MHz) Desense 4~7dB，Normal正常
- **排查过程**：排除MIPI Clock、MCLK、电源SSN后，关闭OIS干扰改善，屏蔽Wide模组驱动IC干扰完全消失
- **解决方案**：OIS Driver IC局部屏蔽罩
- **根本原因**：OIS Driver IC本体辐射宽带EMI，通过空间耦合到WiFi天线
- **教训**：定位到具体模组后，应立即做子功能逐项排查（OIS/AF/Flash等零成本软件操作），避免按常规时钟→电源路径逐一排除导致排查周期拉长

## 八、附录

### 术语表
- **RSSI**：Received Signal Strength Indication，接收信号强度指示
- **PER**：Packet Error Rate，包错误率
- **吞吐量**：Throughput，数据传输速率
- **共模噪声**：Common Mode Noise，共模干扰
- **信道**：Channel，无线通信频段划分
- **OIS**：Optical Image Stabilization，光学防抖
- **AF**：Auto Focus，自动对焦
- **VCM**：Voice Coil Motor，音圈马达（AF驱动执行器）
