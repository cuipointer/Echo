## 一、组合信息

### 干扰源
- **模块**：Camera System
- **噪声来源**：MIPI CSI Clock / Data、MCLK、AVDD 电源 SSN
- **基频范围**：MIPI CSI(200-800MHz)、MCLK(24-27MHz)、AVDD SSN(宽带噪声)

### 受扰体
- **频段**：LTE Low Band
- **频率范围**：700-960 MHz
- **敏感度要求**：-95 ~ -105 dBm（接收灵敏度）

### 耦合路径
- **类型**：传导耦合、辐射耦合
- **机制**：电源噪声通过电源平面传导；低频谐波空间辐射

## 二、理论预判

### 谐波命中计算

#### MCLK谐波分析
MCLK典型值为24MHz或27MHz：
- 24MHz × 29.17 = 700MHz ✓ 命中LTE LB低端
- 24MHz × 40 = 960MHz ✓ 命中LTE LB高端
- 27MHz × 25.93 = 700MHz ✓ 命中LTE LB低端

#### MIPI CSI谐波分析
低频谐波能量较强，更容易造成干扰：
- MIPI Clock 400MHz × 1.75 = 700MHz ✓ 低次谐波命中
- MIPI Clock 300MHz × 2.4 = 720MHz ✓ 低次谐波命中

**结论**：Camera低频谐波可能命中LTE LB频段，低次谐波能量更强

### 设计审查必查项
1. **低频谐波控制**：低频谐波的滤波和屏蔽设计
2. **电源低频噪声**：AVDD在700-960MHz频段的噪声抑制
3. **共模传导路径**：电源接口共模滤波有效性
4. **天线低频隔离**：LTE LB天线与Camera的低频隔离
5. **低频屏蔽设计**：低频电磁屏蔽材料选择
6. **接地系统完整性**：低频接地回路设计

## 三、软件排查步骤

### 步骤 1：场景复现
**目标**：确认Camera相关干扰现象可复现

**操作**：
1. 进入测试场景：前摄/后摄预览或录像模式
2. 测量LTE LB性能：记录RSRP、SINR、吞吐量等指标
3. 扫描各频段：检查B5/B8/B12/B13/B17等关键频段
4. 记录干扰现象：描述灵敏度恶化程度

**预期结果**：Camera开启时LTE LB灵敏度稳定恶化

### 步骤 2：干扰源确认
**目标**：确认干扰源为Camera相关模块

**操作**：
1. 关闭Camera应用：观察干扰是否消失
2. 切换前后摄像头：对比干扰差异
3. 分辨率影响测试：对比不同分辨率的干扰程度
4. 电源状态监测：观察Camera功耗变化与干扰关联

**预期结果**：确认干扰与Camera工作状态相关

### 步骤 3：频率验证
**目标**：验证干扰频率与理论预判一致

**操作**：
1. 读取当前MIPI Clock配置
2. 计算低次谐波：验证2-4次谐波与LTE LB频段关系
3. 频谱仪观察：使用低频探头观察700-960MHz频段
4. 频段分布分析：确认干扰是否集中在特定LTE频段

**预期结果**：低次谐波命中LTE LB频段

### 步骤 4：软件规避尝试
**目标**：尝试软件措施改善干扰

**操作**：
1. 尝试MIPI SSC：
   - 开启SSC功能分散谐波能量
   - 测量改善效果：记录RSRP改善
2. 尝试频率调整：
   - 调整MIPI Clock避开风险频率
   - 测量改善效果：记录SINR改善
3. 尝试功耗优化：
   - 优化Camera功耗控制策略
   - 测量改善效果：记录干扰降低

**预期结果**：LTE LB性能可接受恢复

## 四、硬件排查步骤

**触发条件**：软件措施无效或改善不足

**目标**：确认低频耦合路径

**操作**：
1. 低频近场扫描：使用700-960MHz频段探头
2. 电源传导测试：测量电源端低频噪声
3. 共模路径验证：验证共模滤波效果
4. 接地系统检查：检查低频接地完整性

**预期结果**：确认低频干扰的主要传播路径

### 步骤 2：硬件整改验证
**目标**：验证低频干扰整改措施

**操作**：
1. 电源滤波增强：
   - 增加低频滤波电路
   - 优化共模滤波器
   - 测量改善效果：低频噪声降低
2. 屏蔽系统优化：
   - 低频屏蔽材料应用
   - 接地系统完善
   - 测量改善效果：辐射干扰降低
3. 布局优化：
   - LTE LB天线位置优化
   - 电源路径隔离

**预期结果**：LTE LB性能满足商用要求

## 六、典型案例

### 案例 1：后摄预览LTE B12灵敏度恶化8dB
- **问题描述**：后摄开启预览时，LTE B12（700MHz）RSRP恶化8dB
- **解决方案**：调整MIPI Clock从350MHz到325MHz，RSRP改善6dB
- **根本原因**：MIPI Clock 350MHz第2次谐波700MHz直接命中B12频段

### 案例 2：前摄录像LTE B8吞吐量下降50%
- **问题描述**：前摄录像时LTE B8（900MHz）吞吐量下降50%
- **解决方案**：开启MIPI SSC并优化电源管理，吞吐量恢复80%
- **根本原因**：MCLK 24MHz第37.5次谐波900MHz命中B8频段
