## 一、组合信息

### 干扰源
- **模块**:Charger IC(Buck/Boost 充电管理芯片)
- **代码**:CH
- **分类**:充电
- **噪声来源**:Buck/Boost 开关频率及纹波、充电电流突变噪声
- **基频范围**:500 kHz - 2 MHz(典型充电器开关频率)
- **典型干扰**:开关谐波密集命中 LTE LB、充电电流突变引起的宽带噪声

### 受扰体
- **频段**:LTE LB(Low Band)
- **代码**:LLB
- **频率范围**:700-960 MHz(B5 / B8 / B12 / B20 / B26 / B28)
- **敏感度要求**:-94 ~ -102 dBm

### 耦合路径
- **主要类型**:**传导耦合**(充电器电源噪声经电源平面进入射频前端)
- **次要类型**:**辐射耦合**(充电线缆 / 充电 IC 本体的高次谐波辐射)
- **机制**:
  - 传导路径:Charger 输出(VPH_PWR)→ 电源平面 → 射频 PA / LNA 电源 → 降低接收灵敏度
  - 辐射路径:充电线缆当天线(低频段波长 30-40 cm,长线缆易辐射)+ Charger IC 屏蔽不良

### 矩阵元信息
- **优先级**:P1 ⭐ 高优先级
- **典型恶化量**:5-12 dB
- **快速诊断提示**:**拔掉充电器**是最直接验证动作

## 二、理论预判

### 谐波命中计算

Charger 开关频率 500 kHz - 2 MHz,谐波覆盖 LTE LB(700-960 MHz):

| 基频 | 谐波次数 | 命中频点 | LTE Band |
|---|:---:|---|---|
| 500 kHz | 1400 | 700 MHz | B12/B17/B28 低端 |
| 500 kHz | 1920 | 960 MHz | B5/B8 高端 |
| 1 MHz | 700 | 700 MHz | B12/B17 |
| 1 MHz | 960 | 960 MHz | B5/B8 |
| 2 MHz | 350 | 700 MHz | B12/B17 |
| 2 MHz | 480 | 960 MHz | B5/B8 |

**结论**:充电器开关基频 1-2 MHz 的高次谐波(350-960 次)密集覆盖 LTE LB 全频段,且充电电流突变产生宽带噪声叠加。

> **与 LLB-04(PMIC Buck)的区别**:两者都是 Buck 类 DCDC 干扰 LTE LB,但 Charger 特有:①充电线缆辐射;②充电电流动态突变(快充尤其严重);③用户可控(拔充电器 = 零成本验证)

### 设计审查必查项

1. **Charger 输出路径滤波**:VPH_PWR / VBAT 路径的 LC / π 型滤波是否到位
2. **充电线布局**:充电线与射频 PA 供电走线是否物理分离
3. **Charger IC 屏蔽**:Charger IC 是否有屏蔽罩或屏蔽层保护
4. **无线充接地**:若支持无线充,无线充弹片 / 线圈下方地平面完整性
5. **USB/充电 BTB 滤波**:BTB 连接处是否有共模扼流圈
6. **快充协议下电压切换频率**:PD / QC 协议下电压切换是否引入低频纹波

**参考案例**:
- EMC 2024 A.3(O3 LTE B28 Normal 3-5 dB,无线充弹片下方次表层大电源泄露,属 LLB-04 但路径相似)
- EMC 2024 C.1([O11-DDR-LLB-aperture.md](../../cases/O11-DDR-LLB-aperture.md),结构性耦合路径可参照)

## 三、软件排查步骤

### 步骤 1:场景复现

**目标**:确认充电场景下 LTE LB Desense 可复现

**操作**:
1. 测量空载(不充电)LTE LB 各频段灵敏度 → 得到基线值
2. 接入充电器(有线 / 无线 / 不同功率档位)
3. 测量充电中 LTE LB 各频段灵敏度 → 得到充电态值
4. 差值 = 充电 Desense 量

**预期结果**:充电态比空载态灵敏度恶化 5-12 dB;不同 Band 差异明显

### 步骤 2:干扰源确认

**目标**:确认干扰源为 Charger 而非其他充电相关模块

**操作**:
1. **拔充电器**:是否完全恢复到空载水平?
   - 是 → 干扰源与充电相关
   - 否 → 可能是其他 Normal 基线问题,转 NORMAL-01/NORMAL-07 排查
2. **换充电器品牌 / 功率**:问题是否变化?
3. **有线 vs 无线充**:两者表现差异?
   - 仅无线充恶化 → 线圈辐射 / 无线充 IC
   - 仅有线充恶化 → 充电线 / 充电端口 / 有线 Charger IC
   - 两者都恶化 → 共同 Charger IC(电池内 Charger)

**预期结果**:定位到具体充电子系统(有线 Charger / 无线充 / 快充协议 IC)

### 步骤 2.5:充电功率档位排查

**目标**:找到干扰最小的充电功率配置(用于方案权衡)

**操作**:
1. 切换充电功率(PD/QC 协议):5W / 10W / 18W / 快充 ...
2. 记录各档位的 Desense 量
3. 观察规律:**快充越高功率通常 Desense 越严重**(电流越大,电源噪声越强)

**预期结果**:得到 Desense ~ 功率曲线,作为硬件整改必要性的判断依据

### 步骤 2.6:多源叠加排查(若步骤 2 单源关断未完全恢复)

**触发条件**:拔充电器只改善部分 Desense,仍有残余

**操作**:按 [`_template.md` 步骤 2.6](../_template.md) 多源叠加排查法

候选源枚举:
- H1:Charger 电源传导
- H2:充电线缆辐射
- H3:充电时激活的其他模块(如屏幕变亮、CPU 升频)

### 步骤 3:频率验证

**目标**:验证干扰频率与 Charger 开关频率的谐波关系

**操作**:
1. 读取 Charger IC 实际开关频率(通过寄存器 / 规格书 / 频谱仪)
2. 计算 1-3 次 / 100-1000 次谐波是否命中目标 Band
3. 频谱仪在 LB 频段观察:充电 vs 空载的谱线差异

**预期结果**:频率关系与理论预判一致;频谱确认特定谐波强度差异

### 步骤 4:软件规避尝试

**目标**:在硬件改版前穷尽软件措施

**操作**:
1. **充电功率限制**:通过软件限制快充档位(步骤 2.5 找到的安全档位),改善 2-5 dB(牺牲充电速度)
2. **Charger 开关频率调整**(若 IC 支持):调到非风险频率
3. **协议切换**:PD → QC → PPS,观察哪种协议干扰最低
4. **充电时段策略**:在非通话场景充电(业务可接受时)

**预期结果**:记录各措施改善幅度,量化软件可解部分

## 四、硬件排查步骤

**触发条件**:软件措施改善不足 4 dB,或业务不可接受功率限制

### 步骤 1:路径确认

**目标**:判定传导 vs 辐射主路径

**操作**:
1. **近场扫描**:Charger IC / 无线充线圈 / 充电 BTB / USB 端口,找出最强辐射点
2. **电源纹波测量**:示波器测 VPH_PWR / VBAT 纹波,LTE LB 频段内的纹波分量
3. **屏蔽测试**:临时在 Charger IC 加屏蔽罩,看改善量
4. **线缆拉距测试**:拉长充电线到 1 m 外,看是否改善(改善 → 线缆辐射主要)

**预期结果**:确定主要路径,指导硬件整改方向

### 步骤 2:硬件整改验证

**目标**:验证整改措施有效

| 整改点 | 措施 | 预期改善 |
|---|---|:---:|
| VPH_PWR 滤波 | π 型滤波(10 μF + 100 nF + 磁珠 BLM18HE152SN1) | 3-6 dB |
| Charger IC 屏蔽 | 加 Charger IC 局部屏蔽罩 | 2-5 dB |
| 充电线缆 | 加共模扼流圈 / 铁氧体磁环 | 1-3 dB |
| 无线充线圈 | 线圈下方加全地孔 + 屏蔽层 | 3-8 dB |
| 充电 BTB | BTB 附近加共模滤波 | 2-4 dB |
| 电源分割 | Charger 输出电源与射频前端电源 LDO 隔离 | 4-10 dB(根治级) |

**预期结果**:综合措施改善到满足限值(内部 ≤ 4 dB)
