# SOP-LLB-03:DDR → LTE LB

**版本**:v0.9.0
**日期**:2026-05-06
**状态**:**方法论版(待现场复测)** — 从 placeholder v0.1 升级,基于 EMC 2024 C.1 案例反哺 + W24-03 结构参照,**未经现场实测验证**

> **复测提醒**:DDR 基频 200-933 MHz 不直接命中 LB(700-960),本 SOP 重点在"结构性辐射路径"诊断;现场需结合具体机型的前摄 / 底盖 / FPC 布局验证。

---

## 一、组合信息

### 干扰源
- **模块**:DDR(Double Data Rate SDRAM,含 DDR Controller + DDR PHY)
- **代码**:DD
- **分类**:存储
- **噪声来源**:内存时钟、数据线开关噪声、DDR PHY 训练突发、DDR VDD 电源纹波
- **基频范围**:200-933 MHz(典型 LPDDR5 / LPDDR4X / LPDDR4)
- **典型干扰特征**:**宽带底噪**(而非单点谐波尖峰),DDR 高负载时 700-960 MHz 范围整段抬升

### 受扰体
- **频段**:LTE LB(低频段)
- **代码**:LLB
- **频率范围**:700-960 MHz
- **典型频段**:B5(850)、B8(900)、B26(850)、B28(700-800)、B12/B13/B17(700)
- **敏感度要求**:-102 ~ -108 dBm(LB 频段典型值,比 MHB 更敏感)

### 耦合路径

**主路径:结构性辐射路径**(本 SOP 核心诊断点)

| 结构开窗点 | 泄露机制 | 对下天线影响 |
|---|---|---|
| **前摄破洞 / 开孔** | DDR 噪声从主板腔体经前摄开孔辐射 | 对 B8/B26 影响大(路径最短) |
| **BTB 缝隙** | 主 FPC BTB / 屏 BTB 连接处缝隙 | 对 B5/B8 影响大(BTB 附近走线密集) |
| **FPC 走线间隙** | FPC 经过的结构缝隙(屏 FPC / 电池 FPC) | 视 FPC 路径而定 |
| **中框缝隙** | 中框与主板 / 电池仓 / 后盖接合缝隙 | 对 B5/B26 影响(中框面传导) |
| **下天线 physical location** | 下天线距离 DDR / 主板腔体过近 | 整段 LB 整体抬升 |

**关键机制**:DDR 基频 200-933 MHz **不直接**与 LB 700-960 MHz 形成单次谐波命中关系(DDR 一次谐波本身就可能命中 LB,但**这不是主导贡献**);真正的问题是 DDR 高负载时的**宽带底噪** + **电源 SSN** 经上述结构开窗**整体辐射**到下天线。

**次路径**:
- **传导耦合**:DDR VDD 电源平面纹波经 PCB 平面传到 RFFE / PA 供电(次要,占比低)
- **单次谐波命中**:DDR 特定频率(如 850 MHz)一次谐波直接落 B5/B26,这种情况理论存在但现场少见,多为结构路径叠加

### 矩阵元信息
- **优先级**:P1
- **典型恶化量**:3-8 dB(EMC C.1 案例 B8/B5/B26 均在 3-5 dB)
- **快速诊断提示**:**停止下载 / 高带宽 DDR 负载** + **近场扫描前摄区域**

## 二、理论预判

### 为什么 DDR 基频不直接命中,问题却出在 LB?

DDR 基频 200-933 MHz 与 LB 700-960 MHz **存在频段重叠**,但:

1. **DDR 一次谐波能量分散**:DDR 工作频率随 DVFS 动态跳变,即使某档恰好落 850/900 MHz,单点谐波尖峰远低于整段底噪
2. **真正危险的是宽带底噪**:DDR 高负载时,所有数据线 / 时钟 / PHY 训练产生的高频噪声叠加成一段 **宽带噪声平台**,覆盖整个 200 MHz ~ 1 GHz
3. **LB 处于这段底噪的高频端**,同时 LB 接收机敏感度最高(-102 ~ -108 dBm)

所以本 SOP 不做"谐波命中表",而是分析**结构路径**。

### 结构开窗等效天线原理

任何金属腔体(手机中框 + 屏蔽罩构成的"屏蔽盒")上的**开窗 / 缝隙**,对某个频率而言,若其长度 ≈ λ/2 或 λ/4,则**等效为一个辐射缝天线**。

| LB 频段 | 波长 λ | λ/2 | λ/4 |
|---|:---:|:---:|:---:|
| 700 MHz | 429 mm | 214 mm | 107 mm |
| 850 MHz | 353 mm | 176 mm | 88 mm |
| 900 MHz | 333 mm | 167 mm | 83 mm |
| 960 MHz | 312 mm | 156 mm | 78 mm |

**推论**:前摄破洞 / BTB 缝隙虽然只有几 mm 至十几 mm,但:
- 这些缝隙**不需要达到 λ/4** 就能辐射(效率低但不为零)
- 手机内部 DDR **近场能量密度高**,少量泄露就足以让下天线吃到
- **多个开窗同时存在** → 多点泄露叠加

### 设计审查必查项

| # | 检查项 | 关键指标 | 备注 |
|:---:|---|---|---|
| 1 | **前摄破洞大小** | 开孔直径 / 长宽 | 越大泄露越严重,必查 |
| 2 | **BTB 缝隙** | 主 FPC BTB / 屏 BTB 压合质量 | 装配偏差直接导致缝隙 |
| 3 | **FPC 走向** | 是否穿过敏感路径 | FPC 本身也是辐射体 |
| 4 | **下天线 physical location** | 与 DDR 腔体最近距离 | < 10 mm 高危 |
| 5 | **中框接合质量** | 中框 / 后盖 / 电池仓接合缝隙 | 产线装配一致性 |
| 6 | **屏蔽罩-中框接地** | DDR 屏蔽罩与中框的导电连接 | 导电泡棉 / 弹片 |
| 7 | **小板支架装配** | 小板 + 支架 + 中框公差 | EMC C.1 实战关键发现点 |

**参考案例**:
- **主驱动**:[O11-DDR-LLB-aperture.md](../../cases/O11-DDR-LLB-aperture.md) — O11 B8/B5/B26 3-5 dB,前摄破洞 + BTB 缝隙 + 装配偏差三者叠加
- 参照 SOP:[W24-03](../W24/W24-03.md) DDR → WiFi 2.4G,同源但路径不同

## 三、软件排查步骤

### 步骤 1:场景复现 & Normal 基线

**目标**:确认 DDR 场景下 LB Desense 可复现,并与 Normal 对齐

**操作**:
1. **Normal Desense 测试**(基线):空载 / 无 DDR 高负载,测各 B5/B8/B26/B28 灵敏度
2. **DDR 高负载场景**:启动下载 / 大游戏 / 压测,使 DDR 跑到高带宽 / 高频档
3. 差值 = DDR 场景 Desense
4. **多频段对比**:同时记录 B5/B8/B26,看是否**多频段同步恶化**(结构路径典型特征)

**预期结果**:
- Normal ≤ 1 dB(达基线)
- DDR 场景多个 LB 频段同步恶化 3-8 dB → **结构路径嫌疑高**(若只有单频段恶化 → 回到单次谐波排查)

### 步骤 2:干扰源确认

**目标**:确认 DDR 为主要干扰源,并初步收敛路径

**操作**:
1. **停止高带宽 DDR 负载**:Desense 是否恢复?
   - 是 → 确认 DDR 相关
   - 否 → 可能叠加 CPU / 电源,转多源排查
2. **DDR 降频 / 降带宽**(若系统支持):观察各 LB 频段改善程度
3. **主分集对称性检查**:
   - **主集恶化 > 分集** → 通常主集天线靠近 DDR,结构路径嫌疑
   - **主集 ≈ 分集同步恶化** → 全机层级辐射(EMC C.1 的特征)
   - **分集 > 主集** → 下天线(通常是分集)结构路径嫌疑

**预期结果**:DDR 负载与 Desense 强相关;主分集对称性给出路径初判

### 步骤 2.5:子功能逐项排查

**目标**:排除下载场景中其他功能(USB / 屏 / Camera)的混淆

**操作**(按零成本顺序):
1. 关屏(排除屏 MIPI)
2. 断 USB(排除 USB 3.0 干扰)
3. 纯内存压测(不跑网络 / 摄像头)
4. 关 WiFi / BT(排除自干扰,LB 不常见但要排除)

**预期结果**:隔离出 DDR 单独贡献的 LB Desense

### 步骤 2.6:多源叠加排查(若对称性异常或改善量对不齐)

**触发条件**:步骤 2.5 排除其他功能后 Desense 残余大,或 DDR 降频改善不线性

**操作**:按 [`_template.md` 步骤 2.6](../_template.md) 多源叠加排查法,候选源:
- H1:DDR 宽带底噪(结构路径)
- H2:CPU 屏蔽罩泄露(CPU 也高负载)
- H3:电源 SSN(DDR 大电流纹波)
- H4:**叠加的结构路径**(前摄 + BTB 两条路径同时存在)

**注意**:LLB-03 的多源叠加通常是**同一个源(DDR)经多条结构路径**,而非多个源各自贡献 —— 与 [LHB-03](../LHB/LHB-03.md) 的"多源"定义不同。

### 步骤 3:频谱验证(**本 SOP 重点**)

**目标**:定位结构泄露点(非"验证某次谐波")

**操作**:
1. **近场扫描 — 前摄区域**:
   - 近场探头 H-field / E-field
   - 中心频率 850 / 900 MHz,扫描带宽 ± 50 MHz
   - 前摄开孔正上方 / 周围 5mm 移动,记录场强峰值
2. **近场扫描 — BTB 区域**:主 FPC BTB 四周 / 屏 BTB 四周
3. **近场扫描 — 下天线附近**:下天线 feed 点 / 走线路径上是否有额外噪声耦合
4. **中框缝隙扫描**:中框 / 后盖 / 电池仓接合线
5. **谱形观察**:应看到**宽带抬升**(非尖峰),DDR 负载启停时整段底噪起伏

**预期结果**:定位出**最强泄露点**(EMC C.1 案例:前摄破洞处最强)

### 步骤 4:软件规避尝试(效果有限,但先试)

**目标**:软件优先原则,拆机前先确认软件上限

**操作**:
1. **DDR DVFS 避让**:通话 / 弱场景下锁定 DDR 低频档(牺牲性能)
2. **调度避让**:通话时降低后台 DDR 访问(调度器策略)
3. **DDR Refresh 优化**:降低 Refresh 率(微小改善)

**预期结果**:通常改善 **0.5-2 dB**,**对结构路径基本无效**(C.1 案例印证);需进入硬件排查

## 四、硬件排查步骤(**本 SOP 主路径**)

**触发条件**:软件措施改善不足 3 dB,或现场定位到明确结构泄露点

> **重要**:EMC C.1 案例中软件措施基本无改善,问题通过**BTB 电容滤波 + 结构装配修正**两阶段整改解决,硬件措施才是本 SOP 的核心。

### 步骤 1:结构路径近场定位

**目标**:精确定位主泄露点,指导后续整改方案选择

**操作**:
1. **近场扫描三点定位**:前摄 + BTB + 下天线周围
2. **铜箔临时封堵测试**:
   - 用铜箔贴住前摄破洞 → 观察改善
   - 用铜箔压住 BTB 缝隙 → 观察改善
   - 用铜箔缠中框缝隙 → 观察改善
3. **排序**:按封堵后的改善 dB,排出各泄露点贡献排序
4. **拆解复现**:部分改善可能依赖拆装偏差,重复装配 2-3 次验证一致性

**预期结果**:得到**排序后的泄露点清单**(例:前摄 4 dB > BTB 2 dB > 中框 1 dB)

### 步骤 2:BTB 电容滤波(EMC C.1 实战第一阶段)

**目标**:在 BTB 连接处加电容,滤除 DDR 噪声进入 FPC / 屏侧的通路

**操作**:
1. **主 FPC BTB 加电容**:在对 DDR 敏感的信号/电源 pin 上加 pF 级电容到 GND(具体值按现场频谱确定)
2. **屏 BTB 加电容**:同上,特别针对屏 FPC 靠近下天线的走线
3. **整改后复测**:记录 B8/B5/B26 各频段改善量

**EMC C.1 实战效果**:**B8 主要改善点**(BTB 滤波后 B8 恢复到 < 2 dB),**B5/B26 改善有限**(因为路径不完全在 BTB 上)

### 步骤 3:结构装配修正(EMC C.1 实战第二阶段)

**目标**:消除结构装配偏差导致的缝隙

**操作**:
1. **拆小板支架 + 重新组装**:按产线标准装配,检查压合到位
2. **装配一致性检查**:
   - 小板 + 支架公差
   - 前摄模组压合
   - 屏 BTB 压合力
3. **复测各频段**:对比装配前后 B5/B26/B8 的改善

**EMC C.1 实战效果**:**B5/B26 主要改善点**(结构装配修正后 B5/B26 恢复到 < 2 dB)

**关键认知**:**"结构装配偏差"是 Desense 最隐蔽的根因之一**,产线一致性直接决定最终表现。

### 步骤 4:前摄破洞填充 / 屏蔽(长期措施)

**目标**:从物理结构上消除前摄破洞这个辐射源

**操作**:
1. **前摄模组内壁贴导电泡棉** → 封闭腔体
2. **前摄开孔处加金属屏蔽罩** → 只留光路
3. **前摄 FPC 包屏蔽层**

### 硬件整改汇总(C.1 实战反哺)

| 整改点 | 措施 | 预期改善 | 适用频段 |
|---|---|:---:|---|
| **主 FPC BTB 滤波** | 敏感 pin 加 pF 电容到 GND | 2-4 dB | B8 主要 |
| **屏 BTB 滤波** | 靠近下天线的走线加电容 | 1-3 dB | B8/B5 |
| **结构装配修正** | 拆装小板支架 / 修正公差 | 2-4 dB | **B5/B26** |
| **前摄破洞填充** | 导电泡棉 / 金属屏蔽 | 3-6 dB | B8/B26 |
| **中框接地** | 中框镭雕面 + 弹片就近接地 | 1-3 dB | 全 LB |
| **下天线位置微调** | 远离 DDR 腔体 | 1-3 dB | 全 LB |
| **DDR 屏蔽罩压紧** | 导电泡棉压紧屏蔽罩-中框 | 2-4 dB | 源头削弱 |

**综合预期**:结构路径 + BTB 滤波双管齐下,LB 各频段恢复到 **≤ 2 dB**(EMC C.1 实战达标)

## 六、典型案例

### 案例 1:O11 B8/B5/B26 DDR Desense 3-5 dB(**EMC 2024 C.1 核心案例**)

详见 [O11-DDR-LLB-aperture.md](../../cases/O11-DDR-LLB-aperture.md)

**概要**:
- **机型 / 阶段**:O11 / P0.1
- **现象**:B8(900)、B5(850)、B26(850)**三频段同步** 3-5 dB Desense
- **持续天数**:24 天(反映结构路径诊断难度)

**关键诊断线索**:
1. **多频段同步恶化** → 宽带特征,指向结构路径而非单次谐波
2. **频谱仪确认**:DDR 200-933 MHz **不直接落 LB 700-960**,排除简单谐波命中
3. **近场扫描**:**前摄破洞处**场强最强 → 定位结构耦合点
4. **主分集对称恶化**:作为全机层级辐射的线索

**两阶段整改**:
| 阶段 | 措施 | 主要改善频段 | 时长 |
|:---:|---|---|:---:|
| 第一阶段 | BTB 电容滤波(主 FPC + 屏 BTB) | **B8** | ~10 天 |
| 第二阶段 | 拆小板支架重新组装(修正装配偏差) | **B5/B26** | ~14 天 |

**反哺知识库**:
- 本 SOP 的"结构路径诊断"章节即来自此案例
- [设计查阅必查项](../../methodology/design-review.md) 新增"前摄破洞 / 下天线距离"条目
- 方法论新增"结构性路径"作为耦合路径的独立分类

- **DDR PHY**:DDR 物理层
- **DVFS**:Dynamic Voltage and Frequency Scaling
- **BTB**:Board-to-Board 连接器,主板与 FPC 间的板对板接头
