# SOP-LHB-04:USB 3.0 → LTE HB

**版本**:v0.9.0
**日期**:2026-05-06
**状态**:**方法论版(待现场复测)** — 从 placeholder v0.1 升级,基于 W5-04(USB3 → WiFi 5G)结构复用 + 频段映射调整,**未经现场实测验证**

> **复测提醒**:LHB 频段(2300-3700 MHz)覆盖比 WiFi 5G 更低,USB3 谐波命中路径与 W5-04 不完全一致,请按实测确认主要命中 band。

---

## 一、组合信息

### 干扰源
- **模块**:USB 3.0(SuperSpeed)
- **代码**:U3
- **分类**:外设
- **噪声来源**:5 Gbps SS 差分信号、USB 3.0 SS 时钟(2.5 GHz)、USB 控制器本体噪声
- **基频范围**:2.5 GHz(SS clock)/ 5 GHz(数据率)
- **典型干扰**:基频直接辐射 + 低次谐波命中;USB 工作时噪声强、不工作时弱

### 受扰体
- **频段**:LTE HB(High Band)
- **代码**:LHB
- **频率范围**:2300-3700 MHz(B7 / B40 / B41 / B42 / B48)
- **敏感度要求**:-94 ~ -102 dBm

### 耦合路径
- **主要类型**:**辐射耦合**(USB 端口 / USB 线缆 / SS 差分走线辐射)
- **次要类型**:**传导耦合**(USB 供电噪声、SS 差分信号通过共模传导)
- **机制**:
  - 5 Gbps SS 差分信号频谱基频 2.5 GHz,直接落在 LHB 下段(B40 2300-2400)
  - USB 2.5 GHz × 1.2 次 = 3 GHz(B42 3400-3600 附近)
  - 长 USB 线缆当天线,低频段辐射显著

### 矩阵元信息
- **优先级**:P1 ⭐ 高优先级
- **典型恶化量**:8-15 dB
- **快速诊断提示**:**USB 连接测试**(USB 连接 / 断开对比)

## 二、理论预判

### 频率命中分析

USB 3.0 SS 信号频谱分析:

| USB 信号 | 频率 | LHB Band 命中 |
|---|---|---|
| SS CLK 基频 | 2.5 GHz | ✓ B40(2300-2400)边缘 |
| SS CLK 第 2 次谐波 | 5.0 GHz | ✗ 超出 LHB |
| SS 数据率 | 5 Gbps(谱密度宽) | ✓ 3 GHz 附近有分量,命中 B42 |
| SS 差分低次谐波 | 2.5~3.5 GHz 连续谱 | ✓ 覆盖 B40 / B41(2496-2690)/ B42 部分 |

**结论**:USB 3.0 基频 2.5 GHz **直接命中**LTE B40;SS 数据率 5 Gbps 的频谱扩展到 3 GHz+ 也可能影响 B42/B41。危害比 USB 3.0 → WiFi 5G(W5-04)更广泛,但恶化量略低(LTE 灵敏度比 WiFi 宽松)。

> **与 W5-04 的差异**:
> - W5-04:USB 2.5 GHz + WiFi 5 GHz,靠谐波(2 次 = 5 GHz)直接命中
> - LHB-04:USB 2.5 GHz + LHB 2.3~3.7 GHz,靠**基频边缘 + 连续谱**命中,多 band 影响,无单一谐波锁定

### 设计审查必查项

1. **USB 3.0 端口位置**:与 LTE HB 天线距离(越远越好)
2. **SS 差分走线**:走线屏蔽 / 共模滤波
3. **USB 连接器 ESD**:ESD 器件是否为 USB 3.0 兼容型号
4. **USB PHY 供电滤波**:USB PHY 供电滤波设计
5. **SS 信号阻抗匹配**:差分 90 Ω 阻抗控制
6. **USB 线缆规范**:要求高质量带屏蔽的 USB 3.0 线缆
7. **USB 接口 EMI 封堵**:USB 金属外壳接地是否良好

## 三、软件排查步骤

### 步骤 1:场景复现

**目标**:确认 USB 3.0 连接下 LTE HB Desense 可复现

**操作**:
1. 空态(不插 USB)测量 LTE HB 各 Band 灵敏度 → 基线
2. 插入 USB 3.0 设备(SSD / 硬盘 / 扩展坞,确保协商到 SS 模式)
3. 启动 USB 数据传输(确保 SS 信号活跃)
4. 测量 LTE HB 灵敏度
5. 差值 = USB 3.0 Desense

**预期结果**:LTE HB 各 Band 恶化 8-15 dB,B40 最严重

### 步骤 2:干扰源确认

**目标**:确认干扰源为 USB 3.0

**操作**:
1. **拔 USB 线**:Desense 是否完全恢复?
2. **切换 USB 模式**(强制 USB 2.0):Desense 是否大幅改善?
   - 是 → 确认是 SS 信号导致(USB 2.0 只到 480 Mbps,谐波范围低)
3. **换不同 USB 3.0 设备 / 线缆**:差异是否显著?
4. **USB 不传输但保持连接**:仅连接是否有 Desense?(区分连接本身 vs 数据传输)

**预期结果**:确认 SS 模式 + 数据传输时最严重

### 步骤 2.5:USB 工作模式排查

**目标**:找出干扰最小的 USB 配置

**操作**:
1. USB 2.0 vs USB 3.0 切换(软件可控)
2. USB 低功耗模式(Link Power Management)开启验证
3. USB Link State 监控:U0(活跃)vs U1/U2/U3(低功耗)下 Desense 差异

**预期结果**:
- USB 2.0 模式恶化通常消失(代价是传输速度 480 Mbps 而非 5 Gbps)
- USB 低功耗模式间隙性地恢复

> **参考 EMC 2024**:O81 合路信令 USB3 空载场景 Desense,未开启低功耗模式时 Fail 3 dB,**合入打开 USB 低功耗的软件版本后解决**。

### 步骤 3:频率验证

**目标**:验证干扰频率为 USB 3.0 SS 信号

**操作**:
1. 频谱仪在 LTE HB 频段观察:USB 连接前后谱线差异
2. 确认 2.5 GHz 附近有强信号(USB SS CLK 基频)
3. 宽带扫描看是否有 3~3.5 GHz 的连续谱(数据率贡献)

**预期结果**:2.5 GHz 附近强烈尖峰 + 宽带背景噪声抬升

### 步骤 4:软件规避尝试

**目标**:软件层面缓解

**操作**:
1. **强制 USB 2.0**:系统层配置 USB 仅协商 USB 2.0(**最有效**,牺牲速度)
2. **开启 USB 低功耗**:LPM 策略(EMC O81 案例的解决方案)
3. **数据传输调度**:非通话时再做大数据传输
4. **USB 接口禁用 on-call**:通话时切 USB Controller 为低功耗

**预期结果**:USB 2.0 模式改善 ≥ 10 dB(几乎完全消除);LPM 改善 2-4 dB

## 四、硬件排查步骤

**触发条件**:业务不允许限制到 USB 2.0(需要 SS 传输),软件措施不足

### 步骤 1:路径确认

**目标**:定位主要泄露路径

**操作**:
1. **近场扫描**:USB 端口 / USB PHY 周围 / SS 差分走线 / USB 屏蔽盖
2. **USB 端口屏蔽测试**:临时在 USB 端口外加屏蔽,看改善
3. **线缆拉距 / 换线**:高质量屏蔽线 vs 普通线对比
4. **USB PHY 屏蔽罩测试**:临时屏蔽 USB PHY 区域

**预期结果**:识别辐射主路径(端口 / 线缆 / PHY)

### 步骤 2:硬件整改验证

| 整改点 | 措施 | 预期改善 |
|---|---|:---:|
| USB 端口 EMI | USB 金属壳接地优化 | 2-4 dB |
| SS 差分走线屏蔽 | 走线增加屏蔽包地 / 共模扼流圈 | 2-4 dB |
| USB PHY 屏蔽 | USB PHY 区域屏蔽罩 / 铜箔屏蔽 | 3-6 dB |
| USB PHY 供电滤波 | VBUS / VIO_USB 加磁珠 + 电容 | 1-3 dB |
| USB 线缆 | 强制使用屏蔽型 USB 3.0 线缆(SoP 供应商) | 2-5 dB(当问题在线缆) |
| 天线 / 端口距离 | LTE HB 天线与 USB 端口物理拉距 | 1-4 dB(结构设计改) |
| ESD 器件 | 使用 USB 3.0 低寄生 ESD 器件 | 1-2 dB |

**预期结果**:综合改善到限值(内部 ≤ 4 dB,Class 3 ≤ 6 dB)

## 六、典型案例

### 案例 1:EMC 2024 — O81 USB 低功耗模式未开启

- **问题描述**:O81 合路信令 USB3 空载场景 Desense Fail,平均值 Fail 3 dB
- **根因**:USB 工作在非低功耗模式,USB 工作噪声强
- **解决方案**:6.28 号及以后的版本合入打开 USB 低功耗
- **关键教训**:软件 LPM 策略对 USB 干扰控制有显著效果,**量产前必须验证 USB 低功耗正常工作**
