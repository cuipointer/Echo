# SOP-LHB-03:DDR → LTE HB

**版本**:v0.9.0
**日期**:2026-05-06
**状态**:**方法论版(待现场复测)** — 从 placeholder v0.1 升级,基于 EMC 2024 C.2 案例反哺 + W24-03 结构参照,**未经现场实测验证**

> **复测提醒**:DDR → LHB 常呈多源叠加(CPU 屏蔽 + 摄像 FPC / 布线)形式,本 SOP 强化"多源叠加排查法";现场请按具体屏蔽 + FPC 布局验证。

---

## 一、组合信息

### 干扰源
- **模块**:DDR(Double Data Rate SDRAM,含 DDR Controller + DDR PHY)
- **代码**:DD
- **分类**:存储
- **基频范围**:200-933 MHz(典型 LPDDR5 / LPDDR4X / LPDDR4)
- **噪声来源**:内存时钟、数据线开关噪声、DDR PHY 训练突发噪声;大电流开关引发的电源 SSN
- **典型干扰**:**宽带高频底噪**覆盖 MHB 多 Band;高次谐波命中 LHB 单/多信道;**多场景下常与 CPU 屏蔽罩泄露 / 摄像 FPC 辐射叠加**

### 受扰体
- **频段**:LTE HB(MHB/LHB,含 N77/N79/B40/B41/B38/B42 等 multi-Band)
- **代码**:LHB
- **频率范围**:2300-3700 MHz
- **敏感度要求**:-94 ~ -102 dBm

### 耦合路径
- **主要类型**:**辐射耦合(结构性路径为主)**
  - CPU 屏蔽罩焊点 / 开窗 / 胶量不均 → 辐射
  - 主摄 / 前摄 FPC 走线路径 → 辐射
  - 屏蔽罩与中框间隙 → FPC 噪声从腔体逸出
- **次要类型**:**传导耦合**(DDR VDD 纹波经电源平面耦合到 MHB 前端)
- **机制**:
  - 辐射路径 1:DDR 高频时钟从 CPU 屏蔽罩缝隙泄露 → ANT3(MHB 天线)
  - 辐射路径 2:DDR 噪声耦合到主摄 FPC → FPC 本体成二次辐射源 → 经屏蔽罩-中框间隙到达 MHB 天线
  - **多源叠加**:两条辐射路径**同时存在且非互斥**,单一路径整改后常仍有残余(见 O11U 案例 42 天耗时教训)

### 矩阵元信息
- **优先级**:P1
- **典型恶化量**:3-8 dB(单源);**多源叠加可达 7-11 dB**(O11U 前后摄场景)
- **快速诊断提示**:**停止 DDR 高负载 + 关摄像**(同时关断验证是否多源叠加)

## 二、理论预判

### 谐波命中计算

DDR 基频 200-933 MHz,3-12 次谐波可命中 LHB(2300-3700 MHz):

| DDR 基频 | 谐波次数 | 命中频点 | 是否命中 LHB(2300-3700) | 典型 Band |
|---|:---:|---|:---:|---|
| 200 MHz | 12 | 2400 MHz | ✓ B40 边缘 | B40 |
| 300 MHz | 8 | 2400 MHz | ✓ B40 | B40 |
| 400 MHz | 6 | 2400 MHz | ✓ B40 | B40 |
| 400 MHz | 8 | 3200 MHz | ✓ N77/N78 | N77 |
| 600 MHz | 4 | 2400 MHz | ✓ B40 | B40 |
| 600 MHz | 5 | 3000 MHz | ✓ B42/N78 | N78 |
| 800 MHz | 3 | 2400 MHz | ✓ B40 | B40 |
| 800 MHz | 4 | 3200 MHz | ✓ N77/N78 | N77 |
| 933 MHz | 3 | 2800 MHz | ✓ B41 | B41 |
| 933 MHz | 4 | 3732 MHz | ~ 边缘 | N77 上沿 |

**结论**:主流 DDR 频率都存在多次谐波命中 LHB;**LHB 横跨 1.4 GHz,几乎无法通过单一 DDR 调频避开**。因此 LHB-03 比 LHB-01(窄带谐波)更难通过软件规避。

### 多源叠加模式的理论预判(本 SOP 关键)

DDR → LHB 的实战经验表明,**单一"DDR 直辐射"很少是全部原因**。典型场景下同时存在:

| 源 | 机制 | 激活条件 |
|---|---|---|
| H1:CPU 屏蔽罩泄露 | CPU/DDR 在同一屏蔽罩下,缝隙/点胶不均 | DDR 高负载 |
| H2:主摄 FPC 辐射 | 摄像 FPC 接收 DDR 噪声成二次辐射源 | 相机开启 |
| H3:DDR 高频带宽模式 | DDR 进入高频档位,谐波能量密度上升 | 大带宽压测 |

**三假设非互斥,同时存在是常态**。传统"单一源"诊断会在排除 H1 后继续看到 H2 的恶化,导致诊断回圈。

### 设计审查必查项

1. **CPU/DDR 屏蔽罩密封性**:屏蔽罩焊点完整、点胶均匀、无开窗
2. **CPU 屏蔽罩与中框贴合面**:导电泡棉 / 导电胶 / 接触电阻
3. **主摄 / 前摄 FPC 走向**:FPC 是否绕行 CPU 屏蔽罩附近
4. **主摄 BTB 接地**:BTB 连接器附近的地孔密度
5. **屏蔽罩-中框间隙**:腔体噪声是否从间隙逸出到天线
6. **DDR 电源滤波**:VDD_MX / VDDQ 路径的大容值滤波
7. **ANT3(MHB 天线)布局**:天线与 CPU / 摄像 FPC 的物理距离
8. **中框接地点**:单点接地位置是否靠近主摄 BTB 反面(O11U 整改位置)

**参考**:[O11U-LHB-multisource.md](../../cases/O11U-LHB-multisource.md) — MHB 7-11 dB 多源叠加典型案例

## 三、软件排查步骤

### 步骤 1:场景复现

**目标**:在多场景下分别测出 Desense,判断是否场景间数值差异明显(多源叠加的信号)

**操作**:
1. **Normal 基线**:空载测 LHB 全 Band 信道平坦度(基准)
2. **DDR 高负载 only**:跑内存压测/下载,但关摄像,测 LHB
3. **前摄场景**:前摄开启 + DDR 负载,测 LHB
4. **后摄场景**:后摄开启 + DDR 负载,测 LHB
5. 对比各场景 Desense 值

**预期结果**:
- 若四个场景 Desense 值接近 → 单一源(按 LHB-03 单源路径走)
- **若场景间差异 > 2 dB(如前摄 11 dB,后摄 7 dB,DDR only 5 dB)→ 强烈提示多源叠加,直接跳到步骤 2.6**

### 步骤 2:干扰源确认

**目标**:初步确认 DDR 是主要干扰源之一

**操作**:
1. **停止 DDR 压测 / 减负载**:Desense 是否恢复?
   - 是 → DDR 负载相关
   - 否(仍然恶化)→ 强烈提示摄像 FPC 路径(H2)也在作用
2. **切换 DDR 频率**(DVFS):观察干扰频点是否移动
3. **关摄像**:仅停摄像,保留 DDR 压测,看 Desense 变化
4. **关 CPU 高负载**:停跑分,但允许 DDR 读写,看 Desense 变化

**预期结果**:记录每一"单源关断"对 Desense 的贡献 ΔdB,为步骤 2.6 提供数据

### 步骤 2.5:子功能逐项排查(零成本)

**目标**:排除其他同时激活的子功能(USB / Display MIPI / Touch 等)对 LHB 的混合贡献

**操作**(按零成本顺序):
1. 关闭屏幕(排除 Display MIPI 谐波落 MHB)
2. 断开 USB(排除 USB3.0 基频谐波)
3. 关触摸驱动(排除 Touch 时钟)
4. 纯内存压测(不跑网络,排除 WiFi/LTE 自激活)

**预期结果**:隔离出"DDR + 摄像"组合单独贡献的 Desense 量

### 步骤 2.6:多源叠加排查法(本 SOP 核心章节)

> **本章节是 LHB-03 相对其他 SOP 的核心强化**。O11U 42 天耗时教训直接指向:缺乏"多源假设清单 + 分离验证"方法论,导致反复回圈。
> 方法论骨架见 [`_template.md` 步骤 2.6](../_template.md),本节按 LHB-03 场景具体展开。

#### 2.6.1 触发条件(满足任一)

1. 步骤 1 场景复现显示 **≥ 两个场景同时恶化**(如前摄 + 后摄均超 6 dB)
2. 步骤 2 单一源关断后 **Desense 仅部分改善,仍有显著残余**(改善 < 观测值的 60%)
3. 步骤 2.5 子功能全部排除后 **仍有 ≥ 4 dB 残余**
4. 现象表现为"关 A 好一点、关 B 也好一点,但关 A 不彻底根除"

#### 2.6.2 单源隔离测试

枚举本 SOP 的典型三候选源:
- **H1**:CPU 屏蔽罩泄露(→ 临时贴铜箔 / 压导电泡棉做隔离)
- **H2**:主摄 FPC 辐射(→ 关摄像 / 临时用金属胶布包 FPC)
- **H3**:DDR 高频带宽模式(→ 降 DDR DVFS 档位 / 关压测)

依次关断,**每次只关一个**,记录改善量:

| 实验 | 关断源 | 观测 Desense | 改善 ΔdB |
|---|---|---|---|
| 基线 | 无关断(全激活) | _____ dB | — |
| E1 | 关 H1(加屏蔽) | _____ dB | ΔdB₁ = _____ |
| E2 | 关 H2(关摄像) | _____ dB | ΔdB₂ = _____ |
| E3 | 关 H3(降 DDR) | _____ dB | ΔdB₃ = _____ |

#### 2.6.3 组合关断测试

在 2.6.2 基础上验证叠加性:

| 实验 | 关断源 | 观测 Desense | 改善 ΔdB |
|---|---|---|---|
| E12 | 关 H1 + H2 | _____ dB | ΔdB₁₂ = _____ |
| E13 | 关 H1 + H3 | _____ dB | ΔdB₁₃ = _____ |
| E23 | 关 H2 + H3 | _____ dB | ΔdB₂₃ = _____ |
| E123 | 全部关断 | _____ dB | ΔdB_total = _____ |

#### 2.6.4 叠加决策表(核心判据)

将组合改善与单源改善的和对比,按下表判断耦合模式:

| 场景 | 判据 | 耦合模式 | 整改策略 |
|---|---|---|---|
| **加性叠加** | ΔdB_total ≈ ΔdB₁ + ΔdB₂ + ΔdB₃(容差 ±1 dB) | 多源独立,路径不重合 | **全部整改**,贡献累加 |
| **主从关系** | ΔdB_total ≈ max(ΔdBᵢ) | 某一源主导,其他源掩藏在主源下 | 先整改主源,然后重新枚举 |
| **抵消关系** | ΔdB_total < max(ΔdBᵢ) | 多源部分相位抵消,某些源合奏反而"好看" | 小心,整改单源反而可能恶化 |
| **非线性放大** | ΔdB_total > ΔdB₁ + ΔdB₂ + ΔdB₃ | 源之间存在调制/互耦 | 罕见,可能要追交调 |

#### 2.6.5 本 SOP 典型结论

O11U 案例的实际观测:
- ΔdB₁(关 CPU 屏蔽泄露,铜箔临时隔离)≈ 3-4 dB
- ΔdB₂(关主摄 FPC,即关摄像)≈ 4-5 dB
- ΔdB₁₂(同时做)≈ 7-8 dB ≈ ΔdB₁ + ΔdB₂ → **加性叠加**
- **结论**:两源必须同时整改,任何单源方案都会留下 3-4 dB 残余

### 步骤 3:频率验证

**目标**:确认命中的具体 DDR 频率/谐波,对应到 MHB 哪个 Band

**操作**:
1. 读取当前 DDR DVFS 档位与频率
2. 计算各档位 3-12 次谐波,标注命中 LHB 的次数
3. 频谱仪在 2300-3700 MHz 扫谱,找到谱线
4. 切换 DDR 档位,观察谱线是否随之移动(确认是 DDR 谐波而非其他源)

**预期结果**:至少一根 DDR 谐波谱线落在恶化 Band 内

### 步骤 4:软件规避尝试

**目标**:软件优先,减轻但不依赖

**操作**:
1. **DDR DVFS 避频**:避开命中关键 Band 的 DDR 档位(代价:性能)
2. **Display 调刷新率**:同一场景下屏 MIPI 也贡献时,降刷新可减 1-2 dB
3. **DDR Refresh 策略**:略降 Refresh 频率可能改善 EMI 底噪(通常 < 1 dB)
4. **场景避免**:业务层错开"前摄 + 大带宽下载"极端组合(权宜)

**预期结果**:软件措施通常改善 1-3 dB,对 **结构性多源路径基本无效**,必须转硬件

## 四、硬件排查步骤

**触发条件**:软件改善 < 3 dB,或步骤 2.6 证实多源叠加

### 步骤 1:近场扫描双定位

**目标**:同时定位 CPU 屏蔽区和摄像 FPC 区两个热区

**操作**:
1. 近场探头扫 CPU 屏蔽罩四边(尤其四角焊点)+ 屏蔽罩开窗区,记录最强点
2. 近场探头扫主摄 FPC 全长 + 主摄 BTB 连接器附近
3. 近场探头扫屏蔽罩与中框贴合缝隙
4. 天线端(ANT3)接频谱仪,做路径相关性对比:哪个近场热点与 ANT3 谱线时间相关性最强

**预期结果**:至少两个热点(CPU 屏蔽某边 + 主摄 FPC 某段),对应 H1 / H2

### 步骤 2:CPU 屏蔽罩加固(应对 H1,来自 O11U 案例实战)

**整改**:
1. **铜箔扩大**:在 CPU 屏蔽罩外再贴一层铜箔,覆盖所有焊点缝隙与开窗
2. **导电泡棉**:导入 **2.5 × 8 × 0.3 mm** 导电泡棉,压紧屏蔽罩与中框贴合面
3. 复测 Desense,记录 ΔdB

**预期改善**:单独改善 3-4 dB(O11U 实测)

### 步骤 3:单点接地(应对 CPU 屏蔽罩与中框间隙)

**整改**:
1. **位置**:CPU 屏蔽罩与中框之间,**主摄 BTB 反面位置**(O11U 实战定位)
2. **方式**:导电泡棉 + 焊点 / 弹片
3. 复测 Desense

**预期改善**:在屏蔽罩整改基础上再改善 2-3 dB

### 步骤 4:摄像 FPC 屏蔽 / 接地优化(应对 H2)

**整改**:
1. 主摄 FPC 走向调整,远离 CPU 屏蔽罩边缘
2. FPC 关键段加金属屏蔽层
3. 主摄 BTB 接地孔密度增加
4. FPC 噪声敏感段包地

**预期改善**:2-4 dB(场景依赖)

### 整改点汇总表

| 整改点 | 针对源 | 措施 | 预期改善 dB |
|---|---|---|:---:|
| CPU 屏蔽铜箔扩大 | H1 | 覆盖焊点缝隙 | 2-3 |
| CPU 屏蔽导电泡棉 2.5×8×0.3 | H1 | 压紧屏蔽-中框 | 1-2 |
| CPU 屏蔽-中框单点接地 | H1 路径 | 主摄 BTB 反面 | 2-3 |
| 主摄 FPC 屏蔽 | H2 | FPC 金属屏蔽 | 2-3 |
| 主摄 BTB 接地加强 | H2 | 地孔密度 | 1-2 |
| FPC 走向调整 | H2 | 远离屏蔽罩 | 1-2 |
| DDR 电源滤波 | 传导路径 | VDD_MX 容值 | 1-2 |
| **综合方案**(H1 + H2 同时整改) | 多源叠加 | 上述组合 | **6-9 dB** |

**预期结果**:综合改善到内部限值(≤ 4 dB)

## 六、典型案例

### 案例 1:O11U MHB ANT3 前后摄场景 7-11 dB(多源叠加,42 天)

**问题描述**:
- 机型 O11U 阶段 P0.1
- **前后摄 DDR 场景** ANT3 MHB Desense **7-11 dB**(多 Band,包括 B40 / B41 / N77 / N79)
- **持续 42 天**未收敛 —— **多源叠加导致分离验证反复回圈,是 42 天耗时的核心原因**

**分析过程**:
1. 初期怀疑单一 CPU 屏蔽罩问题,贴铜箔改善 3-4 dB 但仍有 5-7 dB 残余
2. 转向怀疑主摄 FPC,关摄像改善 4-5 dB 但仍有 3-6 dB 残余
3. 反复回圈两次后,才意识到**两源同时存在**
4. 引入"分离验证表"(类似本 SOP 步骤 2.6.3 的组合关断)确认加性叠加
5. 两阶段整改后总改善 7-9 dB,达到内部限值

**两阶段整改**:
- **阶段 A(H1)**:CPU 屏蔽罩铜箔扩大 + **2.5 × 8 × 0.3 导电泡棉** → 贡献 3-4 dB
- **阶段 B(H1 路径)**:CPU 屏蔽罩与中框之间**单点接地**(主摄 BTB 反面位置)→ 再贡献 2-3 dB
- (摄像 FPC 侧因结构约束未直接改造,通过 CPU 侧整改间接抑制 H2 路径)

**三要素结论**:
- 干扰源:DDR 宽带底噪 + CPU 屏蔽泄露 + 主摄 FPC 辐射(三源叠加,加性)
- 受扰体:LTE MHB ANT3(2300-3700 MHz,多 Band)
- 耦合路径:辐射混合,主摄 FPC 噪声经屏蔽罩-中框间隙到达 ANT3,CPU 屏蔽自身泄露叠加

**教训(42 天反思)**:
1. 缺乏"多源假设清单"方法论 → Sprint 1 已固化到 `_template.md` 步骤 2.6
2. 分离验证表应在发现多场景差异 **立刻展开**,而非反复单源假设
3. 硬件整改应**预留多源叠加工序**(屏蔽 + 接地 + FPC 三项并行,不单项等结果)
4. `/diagnose` Step 4 决策树输出应为**多假设清单**(已在 v2.1 补强)

## 八、附录

### 术语表
- **Desense**:De-sensitization,灵敏度恶化
- **DDR**:Double Data Rate SDRAM,手机多为 LPDDR 版本
- **LPDDR4 / 4X / 5**:手机主流低功耗内存规范
- **LHB / MHB**:LTE High Band / Mid-High Band,2300-3700 MHz
- **ANT3**:O11 系列 MHB 主天线
- **BTB**:Board-to-Board 连接器(主摄与主板的对接)
- **FPC**:Flexible Printed Circuit,柔性电路板(摄像模组常用)
- **DVFS**:Dynamic Voltage and Frequency Scaling,动态调频调压
- **SSN**:Simultaneous Switching Noise,同步开关噪声(DDR 大电流切换引起)
- **多源叠加**:≥ 2 个独立干扰源同时作用于同一受扰体,单源关断仅部分改善
- **分离验证**:对每个候选源单独关断测 ΔdB,再组合关断判断叠加模式

完整术语见 [knowledge/glossary.md](../../glossary.md)。
