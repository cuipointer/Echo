# 干扰源清单

## 干扰源分类

| 大类 | 干扰源模块 | 主要噪声来源 | 典型基频范围 | 优先级 |
|------|------------|--------------|--------------|--------|
| **显示** | LCD MIPI | DSI Clock / Data | 200-800 MHz | 高 |
| | LCD 背光 | PWM 调光 / Boost | 10-50 kHz / 1-2 MHz | 中 |
| **存储** | DDR | 内存时钟 | 200-933 MHz | 高 |
| | eMMC / UFS | 接口时钟 | 50-200 MHz | 中 |
| **摄像** | MIPI CSI | 前后摄时钟 | 200-800 MHz | 高 |
| | Camera AVDD | 模拟电源噪声 | DC / 低频纹波 | 中 |
| **振动** | VIB Motor | PWM 驱动 | 20-50 kHz | 中 |
| **音频** | Speaker PA | Class-D 开关频率 | 300-600 kHz | 中 |
| **充电** | Charger IC | Buck/Boost 开关 | 500 kHz - 2 MHz | 高 |
| **电源** | PMIC Buck | 各路 DCDC 开关 | 1-4 MHz | 高 |
| **外设** | USB 3.0 | SS 5Gbps 信号 | 2.5 GHz / 5 GHz | 高 |

## 详细说明

### LCD MIPI
- **噪声来源**：DSI 时钟和数据线
- **基频范围**：200-800 MHz
- **谐波特性**：谐波丰富，易命中多个频段
- **常见场景**：亮屏常亮、屏幕刷新

### DDR
- **噪声来源**：内存时钟和数据总线
- **基频范围**：200-933 MHz
- **谐波特性**：高频谐波能量较强
- **常见场景**：下载、跑分、多任务

### Camera MIPI
- **噪声来源**：CSI 时钟和数据线
- **基频范围**：200-800 MHz
- **谐波特性**：与 LCD MIPI 类似
- **常见场景**：相机预览、录像

### PMIC Buck
- **噪声来源**：DCDC 开关噪声
- **基频范围**：1-4 MHz
- **谐波特性**：低频谐波丰富
- **常见场景**：待机、低负载

### VIB Motor
- **噪声来源**：PWM 驱动信号
- **基频范围**：20-50 kHz
- **谐波特性**：谐波密集，易命中 GNSS
- **常见场景**：振动提醒、触觉反馈

### Charger IC
- **噪声来源**：Buck/Boost 开关
- **基频范围**：500 kHz - 2 MHz
- **谐波特性**：开关噪声频谱宽
- **常见场景**：充电、快充

### USB 3.0
- **噪声来源**：5Gbps 差分信号
- **基频范围**：2.5 GHz / 5 GHz
- **谐波特性**：高频能量集中
- **常见场景**：USB 数据传输

## 干扰源识别方法

### 1. 场景关联法
- 亮屏 → LCD MIPI / 背光
- 充电 → Charger
- 摄像 → Camera MIPI
- 下载 → DDR
- 振动 → VIB Motor
- 外放 → Speaker PA

### 2. 频率测量法
- 使用频谱仪测量干扰频率
- 对比干扰源基频和谐波
- 确认频率重叠关系

### 3. 开关测试法
- 关闭可疑模块
- 观察干扰变化
- 确认干扰源

### 4. 谐波计算法
- 计算干扰源谐波
- 对比受扰体频段
- 确认命中关系
