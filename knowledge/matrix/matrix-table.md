## 干扰源详细信息

### 系统电源 (PMIC)
- **基频范围**:1-4 MHz
- **噪声来源**:DCDC 开关频率及纹波
- **典型干扰**:高次谐波命中各频段,宽带噪声
- **Normal 影响**:系统级噪声,影响所有频段
- **排查优先级**:高

### 系统时钟 (OSC)
- **基频范围**:26-48 MHz
- **噪声来源**:主时钟/晶振谐波
- **典型干扰**:整数倍谐波命中特定频段
- **Normal 影响**:离散谱线干扰
- **排查优先级**:高

### 射频电源
- **基频范围**:500 kHz - 2 MHz
- **噪声来源**:PA 供电电源开关噪声
- **典型干扰**:传导到射频电路
- **Normal 影响**:射频性能基础噪声
- **排查优先级**:中

### 非线性器件
- **基频范围**:无固定基频
- **噪声来源**:二极管/TVS/ESD 非线性
- **典型干扰**:交调产物落入接收频段
- **Normal 影响**:大小功率差异明显
- **排查优先级**:中

### PA 匹配
- **基频范围**:无固定基频
- **噪声来源**:阻抗失配导致反射
- **典型干扰**:二次辐射干扰
- **Normal 影响**:天线效率降低
- **排查优先级**:中

### 天线 Tuner
- **基频范围**:时钟频率
- **噪声来源**:控制信号及电源噪声
- **典型干扰**:时钟谐波干扰
- **Normal 影响**:天线调谐噪声
- **排查优先级**:中

### 屏蔽泄露
- **基频范围**:宽带
- **噪声来源**:屏蔽不良导致泄露
- **典型干扰**:内部噪声辐射
- **Normal 影响**:系统性辐射问题
- **排查优先级**:中

### 电连接不良
- **基频范围**:无固定基频
- **噪声来源**:接触非线性产生 PIM
- **典型干扰**:交调干扰
- **Normal 影响**:稳定性问题
- **排查优先级**:低

### LCD MIPI
- **基频范围**:60-120 MHz
- **噪声来源**:DSI Clock / Data 线开关噪声
- **典型干扰**:谐波命中各频段(20-40 次谐波)
- **排查优先级**:高

### Camera MIPI
- **基频范围**:200-800 MHz
- **噪声来源**:CSI Clock / Data 线噪声
- **典型干扰**:直接命中或低次谐波
- **排查优先级**:高

### DDR
- **基频范围**:200-933 MHz
- **噪声来源**:内存时钟及数据线噪声
- **典型干扰**:宽带噪声覆盖多个频段
- **排查优先级**:高

### VIB Motor
- **基频范围**:20-50 kHz
- **噪声来源**:PWM 驱动信号及电机噪声
- **典型干扰**:超高次谐波命中 GNSS 频段
- **排查优先级**:中

### Speaker PA
- **基频范围**:300-600 kHz
- **噪声来源**:Class-D 放大器开关频率
- **典型干扰**:高次谐波干扰
- **排查优先级**:中

### Charger
- **基频范围**:500 kHz - 2 MHz
- **噪声来源**:Buck/Boost 开关频率
- **典型干扰**:充电时电源噪声增大
- **排查优先级**:高

### USB 3.0
- **基频范围**:2.5 GHz / 5 GHz
- **噪声来源**:SuperSpeed 5 Gbps 信号
- **典型干扰**:直接命中高频段
- **排查优先级**:高

## 受扰体详细信息

### Normal
- **说明**:基准场景,所有排查前置条件
- **优先级**:极高

### WiFi 2.4G
- **频率范围**:2412-2484 MHz
- **敏感度要求**:-82 ~ -90 dBm
- **备注**:频段窄,易受邻频干扰
- **优先级**:高

### WiFi 5G
- **频率范围**:5150-5850 MHz
- **敏感度要求**:-76 ~ -84 dBm
- **备注**:频段宽,易受宽带干扰
- **优先级**:高

### LTE LB
- **频率范围**:700-960 MHz
- **敏感度要求**:-94 ~ -102 dBm
- **备注**:穿透力强,易受低频干扰
- **优先级**:高

### LTE HB
- **频率范围**:2300-3700 MHz
- **敏感度要求**:-94 ~ -102 dBm
- **备注**:带宽大,易受高频干扰
- **优先级**:中

### GNSS L1
- **频率范围**:1561-1606 MHz
- **敏感度要求**:-140 ~ -150 dBm
- **备注**:灵敏度极高,微弱干扰即影响性能
- **优先级**:极高

### GNSS L5
- **频率范围**:1176-1176 MHz
- **敏感度要求**:-140 ~ -150 dBm
- **备注**:新频段,干扰场景较少
- **优先级**:高
