## 1. 限值标准

### 企业标准要求
| 标准等级 | 限值要求 | 适用场景 | 备注 |
|:---|:---|:---|:---|
| **企标要求** | ≤ 1.5dB | 所有频段，所有信道 | 产品认证最低要求 |
| **研发内部要求** | ≤ 1dB | 所有频段，所有信道 | 研发阶段目标值 |
| **设计目标** | ≤ 0.5dB | 关键频段 | 理想设计目标 |

> ⚠️ **Normal Desense 是最高优先级的限值要求，必须优先保证。**

### 不同频段敏感度差异
| 频段 | 敏感度要求 | Normal限值 | 特别说明 |
|:---|:---|:---|:---|
| **GNSS L1/L5** | -140 ~ -150dBm | ≤ 0.8dB | 极度敏感，微小干扰即漂移 |
| **WiFi 2.4G** | -82 ~ -90dBm | ≤ 1dB | 常用频段，用户体验关键 |
| **WiFi 5G** | -76 ~ -84dBm | ≤ 1dB | 高频段，受干扰风险高 |
| **LTE LB** | -94 ~ -102dBm | ≤ 1.2dB | 低频段，电源噪声敏感 |
| **LTE HB** | -94 ~ -102dBm | ≤ 1dB | 高频段，时钟谐波敏感 |

## 2. 与其他场景限值对比

### 场景限值对比表
| 场景 | 内部限值 | 优先级 | 叠加特性 | 特别说明 |
|:---|:---|:---|:---|:---|
| **Normal** | ≤ 1dB | **P0（最高）** | 基准线 | 影响所有场景 |
| **LCD** | ≤ 3dB | P1（高） | 叠加在Normal上 | 亮屏场景 |
| **Camera** | ≤ 4dB | P2（中） | 叠加在Normal上 | 摄录场景 |
| **VIB** | ≤ 3dB | P2（中） | 叠加在Normal上 | 振动场景 |
| **Charger** | ≤ 4dB | P2（中） | 叠加在Normal上 | 充电场景 |
| **USB** | ≤ 5dB | P3（低） | 叠加在Normal上 | 数据传输 |

### 场景干扰计算公式
```
场景总干扰 = Normal Desense + 场景额外干扰

例如：
Normal Desense = 1.5dB（超标）
LCD 额外干扰 = 2dB

实际 LCD 场景干扰 = 1.5 + 2 = 3.5dB（超标）

如果先解决 Normal 使其 ≤1dB：
Normal Desense = 0.8dB（达标）
LCD 场景干扰 = 0.8 + 2 = 2.8dB（达标）
```

## 3. 限值判定规则

### 判定条件
1. **频段覆盖**：所有工作频段都需要满足限值
2. **信道覆盖**：每个频段的主要信道都需要测试
3. **温度范围**：高低温环境下限值可适当放宽（≤1.5dB）
4. **样本数量**：至少3台样机测试结果

### 异常处理规则
| 异常情况 | 处理方式 | 备注 |
|:---|:---|:---|
| **单频段超标** | 重点排查该频段干扰源 | 可能是时钟谐波命中 |
| **所有频段超标** | 排查系统级问题 | 电源、时钟、屏蔽等 |
| **个别样机超标** | 排查个体差异 | 焊接、装配、器件差异 |
| **温度变化超标** | 检查温度敏感性 | 器件参数温度漂移 |

## 4. 设计阶段目标

### 设计目标分解
| 设计阶段 | Normal目标 | 关键措施 | 验证方法 |
|:---|:---|:---|:---|
| **原理图设计** | ≤ 2dB | 电源滤波、时钟规划 | 仿真分析 |
| **PCB Layout** | ≤ 1.5dB | 布局隔离、屏蔽设计 | 阻抗控制 |
| **样品验证** | ≤ 1.2dB | 实测优化、参数调整 | 实际测试 |
| **量产优化** | ≤ 1dB | 工艺控制、一致性 | 批量测试 |

### 关键设计参数
| 参数 | 目标值 | 影响 | 测量方法 |
|:---|:---|:---|:---|
| 电源纹波 | < 50mV | 传导噪声 | 示波器 |
| 时钟相位噪声 | < -100dBc/Hz@1MHz | 谐波能量 | 频谱仪 |
| 屏蔽效能 | > 40dB | 辐射泄露 | 近场扫描 |
| 接地电阻 | < 0.5Ω | 接地质量 | 万用表 |

## 5. 测试验证方法

### 测试环境要求
| 项目 | 要求 | 备注 |
|:---|:---|:---|
| **暗室环境** | 符合3GPP标准 | 避免环境干扰 |
| **测试设备** | 校准合格的综测仪 | 确保测试精度 |
| **测试温度** | 常温25℃ ± 5℃ | 标准测试条件 |
| **测试姿势** | 自由空间/手持 | 模拟实际使用 |

### 测试流程
1. **传导基准测试**：直接馈入，记录基准灵敏度
2. **辐射测试**：在暗室环境下测试天线性能
3. **数据处理**：计算辐射-传导差值
4. **统计分析**：多样本、多频段统计分析

### 数据记录格式
```markdown
## Normal Desense 测试记录

### 设备信息
- 设备SN：____
- 测试日期：____
- 测试环境：____

### 测试结果
| 频段 | 信道 | 传导(dBm) | 辐射(dBm) | Desense(dB) | 状态 |
|------|------|-----------|-----------|-------------|------|
| WiFi 2.4G | CH1 | -88 | -83 | 5.0 | ❌超标 |
| WiFi 2.4G | CH6 | -87 | -82 | 5.0 | ❌超标 |
| WiFi 2.4G | CH11 | -86 | -81 | 5.0 | ❌超标 |
| GNSS L1 | - | -145 | -140 | 5.0 | ❌超标 |
| LTE LB | B5 | -100 | -95 | 5.0 | ❌超标 |

### 结论
Normal Desense总体超标，需要系统级整改。
```

## 6. 整改验收标准

### 整改目标
| 整改阶段 | 目标限值 | 验收标准 |
|:---|:---|:---|
| **初步整改** | ≤ 1.5dB | 满足企标要求 |
| **深度整改** | ≤ 1dB | 满足研发要求 |
| **最优整改** | ≤ 0.5dB | 达到设计目标 |

### 验收流程
1. **单机验证**：整改样机测试验证
2. **小批量验证**：3-5台样机一致性测试
3. **温度验证**：高低温环境下稳定性测试
4. **长期验证**：老化测试和可靠性验证
