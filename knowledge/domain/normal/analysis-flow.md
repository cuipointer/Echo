## 标准排查流程

```
Normal Desense 排查入口
    │
    ├── 1. 传导是否正常？
    │       ├── 否 → 先解决传导干扰（非Normal问题）
    │       └── 是 → 继续
    │
    ├── 2. 大小功率是否一致？
    │       ├── 否 → 排查天线周围非线性器件
    │       │        → 排查 PA 与天线匹配是否失配  
    │       │        → 排查电连接不稳定区域
    │       └── 是 → 继续
    │
    ├── 3. 排查交调问题
    │       └── 检查以下器件是否存在非线性：
    │           - LCD（即使灭屏，部分电路仍工作）
    │           - Camera（AVDD 可能常开）
    │           - SPK / 马达 / MIC
    │           - SAR Sensor / 光感
    │           - 天线开关 / TVS
    │           - 音量键 / 电源键 / FPCB
    │
    ├── 4. 排查电源和时钟
    │       ├── 系统电源：PMIC 各 Buck 开关频率
    │       ├── 射频电源：PA 供电 DCDC
    │       └── 系统时钟：主时钟谐波计算
    │
    ├── 5. 排查屏蔽与接地
    │       ├── 近场探头扫描整机
    │       ├── 检查屏蔽盖密封
    │       └── 检查电连接稳定性
    │
    └── 6. 导入解决方案
            ├── 滤波 / 接地 / 屏蔽
            ├── 更换非线性器件
            └── 调整匹配网络
```

## 详细排查步骤

### 步骤 1：传导测试确认

#### 测试目的
确认传导灵敏度正常，排除器件本身问题

#### 操作方法
1. **直接馈入测试**：射频线直接连接到天线接口
2. **基准测试**：记录各频段传导灵敏度
3. **数据记录**：
   ```
   频段       传导灵敏度    辐射灵敏度    Normal Desense
   WiFi 2.4G   -88dBm        -83dBm          5dB
   GNSS L1    -145dBm       -140dBm          5dB
   LTE LB     -100dBm        -95dBm          5dB
   ```

#### 判断标准
- **传导正常**：符合规格要求
- **传导异常**：需要先解决传导问题

### 步骤 2：大小功率一致性检查

#### 测试目的
判断是否存在非线性干扰

#### 操作方法
1. **高功率测试**：最大发射功率下测试灵敏度
2. **低功率测试**：最小发射功率下测试灵敏度
3. **差异计算**：高功率灵敏度 - 低功率灵敏度

#### 判断标准
- **一致性良好**：差异 ≤ 1dB → 线性系统
- **一致性差**：差异 > 1dB → 存在非线性

### 步骤 3：交调问题排查

#### 排查对象
即使灭屏仍可能工作的模块：

| 模块 | 检查项 | 判断方法 |
|------|--------|----------|
| LCD | DDIC是否工作 | 测量DDIC电源电流 |
| Camera | AVDD是否常开 | 检查Camera电源配置 |
| SPK/马达 | 待机电流 | 测量静态电流 |
| 传感器 | 工作状态 | 检查传感器电源 |

#### 排查方法
1. **电源测量**：测量各模块待机电流
2. **功能关闭**：软件关闭可能的功能模块
3. **对比测试**：关闭前后Desense变化

### 步骤 4：电源和时钟排查

#### 电源排查
1. **PMIC开关频率**：
   ```
   Buck1 (CPU): ____ MHz
   Buck2 (GPU): ____ MHz  
   Buck3 (DDR): ____ MHz
   ```
   
2. **谐波计算**：
   ```
   受扰频率 ÷ Buck频率 = 谐波次数
   如：2400MHz ÷ 2MHz = 1200次谐波
   ```

3. **滤波检查**：输出电容、磁珠、layout

#### 时钟排查
1. **系统时钟**：26MHz/38.4MHz等
2. **谐波计算**：
   ```
   受扰频率 ÷ 时钟频率 = 谐波次数
   如：1560MHz ÷ 26MHz = 60次谐波
   ```

3. **时钟质量**：相位噪声、抖动

### 步骤 5：屏蔽与接地排查

#### 屏蔽检查
1. **近场扫描**：使用近场探头扫描整机
2. **热点定位**：找到辐射最强的区域
3. **屏蔽验证**：临时屏蔽验证效果

#### 接地检查
1. **接地连续性**：万用表测量接地电阻
2. **屏蔽盖接地**：检查屏蔽盖与主地连接
3. **结构接地**：检查金属结构件接地

## 关键检查点

| 检查项 | 方法 | 正常标准 | 异常处理 |
|:---|:---|:---|:---|
| 传导灵敏度 | 直接馈入射频口 | 符合规格 | 先解决传导 |
| 大小功率差异 | 对比高/低功率模式 | ≤ 1dB | 查非线性/匹配 |
| 天线驻波比 | 网络分析仪 | VSWR < 2.5 | 优化匹配网络 |
| 屏蔽盖接地 | 万用表测导通 | < 0.5Ω | 改善接地 |
| 电源纹波 | 示波器测量 | < 50mV | 增加滤波 |
| 时钟质量 | 频谱分析仪 | 相位噪声达标 | 优化时钟电路 |

## 软件排查方法

### 电源管理优化
1. **Buck频率调整**：避开敏感频段谐波
2. **展频功能**：开启SSC功能展宽频谱
3. **负载优化**：轻载时降低开关频率

### 时钟配置优化
1. **频率调整**：避开整数倍关系
2. **驱动优化**：降低驱动强度
3. **时序优化**：优化时钟时序

### 功能模块控制
1. **模块关闭**：关闭不必要的功能模块
2. **电源域隔离**：隔离不相关电源域
3. **状态管理**：优化待机状态配置

## 典型问题模式

### 模式 1：宽带恶化
- **特征**：所有频段均匀恶化
- **原因**：电源噪声、屏蔽泄露
- **处理**：电源滤波、屏蔽优化

### 模式 2：特定频段恶化
- **特征**：特定频段严重恶化
- **原因**：时钟谐波、非线性交调
- **处理**：频率调整、非线性排查

### 模式 3：大小功率差异
- **特征**：高/低功率表现不一致
- **原因**：非线性器件、匹配问题
- **处理**：非线性排查、匹配优化
