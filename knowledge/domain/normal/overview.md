## 1. 定义

**Normal Desense** 是指手机在**灭屏且其他功能全部关闭**的状态下，辐射回报值（RSRP 或 RSSI）相对于传导接收回报值的差异。

## 2. 重要性（最高优先级）

> ⚠️ **Normal Desense 是所有场景中最重要的一项。**

原因：
1. **基准线作用**：其他所有场景（LCD、Camera、VIB 等）的干扰都是基于 Normal 条件下叠加的
2. **直接影响 TIS**：Normal Desense 会直接影响天线 OTA 测试的 TIS 结果
3. **排查起点**：任何 Desense 问题都应先确认 Normal 是否达标

## 3. 排查铁律

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   任何场景的 Desense 问题，第一步永远是：                       │
│                                                             │
│   "先确认 Normal Desense 是否达标（≤1dB）"                    │
│                                                             │
│   如果 Normal 不达标 → 先解决 Normal                         │
│   如果 Normal 达标 → 再排查具体场景                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 4. 与其他场景的关系

```
                    ┌─────────────────┐
                    │  Normal Desense │
                    │    （基准线）    │
                    │     ≤ 1dB       │
```

> 场景 Desense = Normal Desense + 该场景的**额外干扰**

## 5. 测试条件定义

### Normal 场景基准条件
- **屏幕状态**：灭屏
- **功能状态**：所有功能关闭（无通话、无数据传输、无充电）
- **系统状态**：仅保持基本系统运行
- **天线状态**：所有天线正常工作

### 测试方法
1. 传导测试：直接馈入射频口，记录基准灵敏度
2. 辐射测试：在暗室环境下测试天线性能
3. 计算差值：辐射值 - 传导值 = Normal Desense

---

## 6. 影响范围

### 直接影响
- **天线 TIS**：直接影响整机天线性能指标
- **所有场景**：Normal 不达标会影响所有场景的最终表现
- **产品认证**：影响运营商认证和产品上市

### 间接影响
- **用户体验**：信号质量直接影响通话和数据传输
- **功耗**：灵敏度恶化导致发射功率增加，功耗上升
- **竞争力**：影响产品在同类产品中的竞争力

---

## 7. 技术特点

### 频率特性
- **宽带干扰**：Normal 干扰通常是宽带噪声
- **无明显峰**：相比场景干扰，Normal 干扰谱线更平坦
- **基础噪声**：代表系统的本底噪声水平

### 耦合特性
- **传导为主**：主要通过电源和地平面传导
- **辐射为辅**：部分通过空间辐射耦合
- **系统性**：涉及整机多个子系统

---

## 8. 设计考量

### 前期设计
- **电源设计**：PMIC 和射频电源的滤波设计
- **时钟规划**：系统时钟频率规划和谐波控制
- **布局优化**：关键器件远离天线区域

### 后期优化
- **软件优化**：电源管理和时钟配置优化
- **硬件整改**：滤波、屏蔽、接地优化
- **测试验证**：系统性测试和验证
