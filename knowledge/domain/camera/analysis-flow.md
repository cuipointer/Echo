# Camera Desense 分析思路

## 标准排查流程

```
Camera 干扰
    │
    ├── 1. 判断 MIPI、MCLK 还是 DDR 干扰
    │       │
    │       ├── 关闭 Camera 预览 → 干扰消失？
    │       │   └── 是 → Camera 相关
    │       │
    │       ├── 切换分辨率/帧率 → 干扰频率变化？
    │       │   ├── 是 → MIPI 相关
    │       │   └── 否 → MCLK 或固定时钟相关
    │       │
    │       └── 对比前后摄 → 差异明显？
    │           └── 定位到具体模组
    │
    ├── 2. MCLK 电路排查
    │       └── 检查 MCLK 上的滤波电容和电阻
    │
    ├── 3. 电源 SSN 噪声排查
    │       └── AVDD/DVDD 纹波测量
    │
    ├── 4. 路径确认
    │       ├── 近场探头扫描 Camera FPC / B2B 区域
    │       └── 确认最强辐射点
    │
    └── 5. 导入方案
            ├── 软件：调整 MIPI 频率 / 开启 SSC
            ├── 硬件：FPC 屏蔽 / 滤波 / 拉远距离
            └── 结构：天线远离 Camera 区域
```

## 限值标准

| 等级 | 限值 | 适用场景 |
|:---|:---|:---|
| Class 2 | ≤ 3dB | GPS 要求 |
| Class 3 | ≤ 6dB | 其他制式（企标） |

**研发内部要求**：≤ 4dB
