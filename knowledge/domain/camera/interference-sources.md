# Camera 干扰源分类（9 类）

| 序号 | 干扰源 | 说明 | 排查优先级 |
|:---|:---|:---|:---|
| a | **时钟和数据的谐波和互调产物** | MCLK/MIPI 时钟谐波 + 数据边沿 | **最高** |
| b | **OIS/AF 驱动 IC 辐射** | OIS Driver PWM 驱动 / VCM 驱动产生宽带 EMI | **高** |
| c | **MIPI I/O 接口电源 SSN 噪声** | 同步开关噪声，通过电源平面耦合 | 高 |
| d | **FPC/B2B 屏蔽不良** | 时钟、信号、电源线辐射泄露 | 高 |
| e | **Camera 模组本身噪声辐射** | Sensor/Driver 自身 EMI | 中 |
| f | **堆叠距离过近** | 天线距离摄像头本体或连接器太近 | 中 |
| g | **主芯片干扰沿 CSI/电源/I2C 传出** | 干扰反向传播，从 Camera 辐射 | 中 |
| h | **DDR/AP 噪音从屏蔽盖泄露** | 系统噪声耦合到 Camera 区域 | 中 |
| i | **激光对焦/TOF/MIC/光感噪声** | 其他辅助功能模块的辐射 | 低 |

> **v2.1 更新说明**：OIS/AF 驱动 IC 辐射从原 h 类（低优先级）提升为 b 类（高优先级）。
> 实际案例表明 OIS Driver IC 本体辐射可造成全频段 4~7dB 宽带 Desense，且为零成本软件可验证（关闭 OIS 即可确认），不应延后排查。

## 快速定位表

| 现象 | 最可能干扰源 |
|:---|:---|
| 预览时干扰，拍照时消失 | MIPI 时钟/数据 |
| 干扰频率随分辨率/帧率变化 | MIPI 相关 |
| **全频段宽带干扰，关闭 OIS 改善** | **OIS Driver IC 辐射** |
| **对焦时干扰加重** | **AF VCM 驱动** |
| 闪光灯开启时干扰 | Flash LED |
| 前后摄干扰表现不同 | 模组布局/FPC 走线差异 |
| 全频段宽带干扰，与时钟频率无关 | 电源 SSN / OIS Driver / 模组本身辐射 |
