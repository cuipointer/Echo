# Camera 电路与电源规格

## 1. 电源列表

| 电源名称 | 用途 | 典型电压 | 噪声风险 |
|:---|:---|:---|:---|
| **DVDD** | Sensor 数字内核供电 | 1.05V ~ 1.2V | 低 |
| **AVDD** | Sensor 模拟部分供电 | 2.8V / 1.8V | **高（模拟敏感）** |
| **VCM** | 音圈马达对焦供电 | 2.8V | 中（驱动时） |
| **GYRO OIS/EIS** | 防抖陀螺仪供电 | 2.8V | 低 |
| **DOVDD** | I/O 接口供电 | 1.8V | 低 |
| **Flash LED** | 闪光灯 | 3.3V~5V | 高（大电流） |
| **TOF 激光** | 激光测距 | 3.3V | 中 |

## 2. 信号线列表

| 信号 | 驱动端 | 接收端 | 说明 |
|:---|:---|:---|:---|
| **MIPI CSI** | Camera 模组 | CPU | 高速图像数据 |
| **MCLK** | CPU | Camera 模组 | 主时钟 |
| **CCI (I2C)** | CPU | Camera 模组 | 控制命令 |
| **RSTN** | CPU | Camera 模组 | 复位信号 |
| **OIS SPI** | CPU | Gyro | 防抖数据 |

## 3. 排查要点

- AVDD 纹波直接影响 Sensor 输出质量
- MCLK 是 Camera 内部 PLL 的参考时钟，频率稳定性关键
- VCM 工作时电流突变，可能产生瞬态噪声
- Flash LED 大电流开关，是强干扰源
