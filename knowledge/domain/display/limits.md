# 亮屏干扰限值定义

## 定义

亮屏 Desense 主要指**屏幕最亮状态下**相对于传导接收灵敏度的干扰值。

## 测试策略

| 测试方式 | 限值等级 | 适用制式 |
|:---|:---|:---|
| Display on + TP on 分开测 | Class 2 | GPS |
| Display on + TP on 合并测 | Class 3 | WiFi/LTE（效率优先） |

## 限值表

| 等级 | 限值 | 适用场景 |
|:---|:---|:---|
| Class 1 | ≤ 1dB | 理想目标 |
| Class 2 | ≤ 3dB | GPS 强制要求 |
| Class 3 | ≤ 6dB | 其他制式可接受上限 |

## 研发内部标准

- 所有制式：≤ 3dB
- 超过 3dB 需启动正式 Debug 流程
