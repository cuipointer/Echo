# TP 工作原理

## 1. 投射式电容原理

- **驱动线路 Tx**：投射电力线
- **感测线路 Rx**：接收电力线，形成电容
- 手指触摸 → 改变电容 → 计算位置

## 2. TP 电源

| 电源 | 用途 | 电压 | 电流 |
|:---|:---|:---|:---|
| DVDD (VDDI) | TP IC 数字部分 | 1.8V | 几 mA |
| AVDD | TP IC 模拟部分 | 3.3V 或 2.8V | 几 mA |

## 3. TP 噪声源

| 噪声类型 | 来源 | 特点 |
|:---|:---|:---|
| **Tx 驱动信号** | 扫描波形 | 周期性，频率 100-400 kHz |
| **TP IC 内部噪声** | 数字/模拟电路 | 宽带或特定频率 |
| **Tx 与射频交调** | Tx 谐波与天线耦合 | 落在接收频段 |

## 4. 排查方法

- 软件关闭 TP 功能，对比干扰变化
- 如干扰消失/减轻 → TP 为干扰源
- 进一步检查 Tx 频率谐波是否命中受扰频段
