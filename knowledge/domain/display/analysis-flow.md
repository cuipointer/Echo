# 亮屏 Desense 分析思路

## 标准排查流程

```
亮屏干扰
    │
    ├── 1. 确认是否 OSC 倍频干扰
    │       ├── 是 → 检查分频电路
    │       └── 否 → 继续
    │
    ├── 2. 检查是否个别信道干扰
    │       ├── 是 → 修改 MIPI 频率或导入跳频机制
    │       └── 否 → 继续
    │
    ├── 3. 软件开关 TP 功能
    │       ├── 干扰变化 → TP 干扰，调整 TP 驱动/时序
    │       └── 无变化 → 继续
    │
    ├── 4. 检查是否 DDR 或晶振时钟异常
    │       ├── 是 → 调整软件驱动强度
    │       └── 否 → 继续
    │
    ├── 5. 检查 TX 大小功率是否异常
    │       ├── 是 → 射频链路问题
    │       └── 否 → 继续
    │
    ├── 6. 检查闪屏是否正常
    │       ├── 异常 → 电源/时序问题
    │       └── 正常 → 继续
    │
    └── 7. 近场探头寻找干扰源和耦合路径
            → 采用滤波、接地或屏蔽措施
```

## 限值标准

| 等级 | 限值 | 说明 |
|:---|:---|:---|
| Class 2 | ≤ 3dB | GPS 要求 |
| Class 3 | ≤ 6dB | 其他制式（Display + TP 合并测试时可放宽） |

**内部研发要求**：≤ 3dB
