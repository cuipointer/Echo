# 亮屏干扰源分类（10 类）

| 序号 | 干扰源 | 说明 | 排查优先级 |
|:---|:---|:---|:---|
| a | **背光电源开关噪声** | WLED PWM / Boost 开关 | 高（仅 LCD） |
| b | **MIPI 时钟倍频干扰** | MIPI DSI Clock 谐波 | **最高** |
| c | **OSC 倍频干扰** | Display IC 内部晶振谐波 | 高 |
| d | **TP 驱动/电源/CLK 噪声** | Tx 扫描信号及谐波 | 中 |
| e | **屏幕 SRAM/T2M 倍频干扰** | 帧缓冲读写时钟 | 中 |
| f | **DDIC 噪声干扰** | Driver IC 内部数字噪声 | 中 |
| g | **DDIC 低频噪声与天线混频** | 低频噪声 + 射频非线性 | 低（特定场景） |
| h | **屏蔽盖密封不良噪音泄露** | 结构/接地问题 | 中 |
| i | **Display Panel 噪声** | 面板自身辐射 | 低 |
| j | **TP 噪声与 Tx 交调干扰** | TP 信号 + 射频互调 | 低 |

## 快速定位表

| 现象 | 最可能干扰源 |
|:---|:---|
| 干扰频率固定，与显示内容无关 | OSC / MIPI 时钟 |
| 干扰随亮度变化 | 背光 PWM |
| 触摸时干扰加重 | TP 相关 |
| 灭屏后干扰完全消失 | 排除非 Display 源 |
| 灭屏后干扰部分残留 | OSC / DDIC 仍在工作 |
