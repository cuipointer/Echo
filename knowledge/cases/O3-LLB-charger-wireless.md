# 案例:O3 LTE B28 Normal 主分集 3~5 dB — 无线充弹片下方电源泄露

**机型**:O3
**阶段**:P1
**现象**:LTE B28 主集 / 分集 Normal 值同步偏低 **3-5 dB**(全低频宽带)
**持续天数**:20 天

---

## 分析流程(Echo 框架)

| Step | 动作 | 输出 |
|:---:|---|---|
| 1. 参数解析 | 受扰体 `LLB`(B28 703-803 MHz)/ 场景 `normal` / "主分集 3-5 dB" | 参数完整 |
| 2. Normal 优先 | 自身即 Normal 基准 | 基线 = 测试自身 |
| 3. **宽窄带判别** | **主分集同步偏低 3-5 dB** → **低频宽带特征**(非单频谐波) | ✓ 保留:电源 SSN / 传导类;✗ 排除:窄带时钟谐波 |
| 4. 决策树 + 矩阵 | `LLB` + 低频宽带 → 候选源 `PMIC`;查矩阵 `PMIC → LLB = LLB-04`(P0 高优先级)→ **H1:PMIC 传导**;结构层:**无线充弹片下方次表层大电源** → H2:无线充关联 | H1+H2:电源系列(非互斥) |
| 5. 三要素结论 | 见下方 | — |
| 6. 后续动作 | 软件无解 → 硬件:**并联低频滤波电容(2 处)** | 硬件层 |

---

## 三要素分析

| 要素 | 内容 |
|---|---|
| **干扰源** | 无线充弹片下方次表层的大电源(电源平面纹波 / SSN) |
| **受扰体** | LTE B28 低频段(703-803 MHz),主集 + 分集对称恶化 |
| **耦合路径** | **传导** —— 电源平面 → PCB 层间耦合 → 射频前端低频滤波不足处 |

---

## 根因

**无线充弹片下方次表层为大电源**(结构设计要求),电源噪声经 PCB 层间传导到低频(B28)敏感处,主分集均受影响说明是**全机层级的电源泄露**而非单路链路问题。

---

## 解决方案

### 硬件措施(最终方案)

1. **泄露噪声处电源并联低频滤波电容**(第一处)
2. **无线充弹片处并联低频滤波电容**(第二处,阻断次表层大电源的噪声传导路径)

### 长期措施

1. **设计查阅必查项扩充**:无线充 / 大电源在 PCB 层叠中的位置需要和 LTE LB(特别是 B5/B8/B28)天线 feed / 低频滤波网络做物理距离 + 层间耦合分析
2. **SOP LLB-04 补充**:增加"无线充相关场景"专项检查段(弹片位置 / 次表层电源 / 层叠策略)
3. **SOP LLB-07 借鉴**(Charger → LLB,Sprint 1 v0.9):本案例虽然根因是无线充(非有线 Charger IC),但传导耦合机制相同,可作为 LLB-07 的参考案例

---

## 架构启示

1. **"无线充 + 大电源 + B28 低频"是典型的电源 + 物理布局复合耦合**。光查电源配置不够,必须结合**结构布局 + PCB 层叠**一起看
2. **设计查阅原则扩展**:不再局限于"电路原理图",必须包含"**带 PCB 层叠 + 结构件 overlay**"的综合设计 review
3. **主分集同步恶化**是重要判据 —— 提示**全机层级**问题(电源 / 地 / 屏蔽),而非单天线 / 单 feed 问题

---

## 反哺 SOP

- **SOP-LLB-04(PMIC → LTE LB)**:补充 Section 二·设计审查增加"无线充弹片 / 次表层大电源"必查项;Section 四·硬件整改增加"并联低频滤波电容(多处)"
- **SOP-LLB-07(Charger → LTE LB)**:Sprint 1 已产出 v0.9;本案例作为**参照典型**(传导耦合机制共享),提示 LLB-07 的 EMC A.3 参考链路也应包含无线充
