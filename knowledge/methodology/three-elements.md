# 三要素模型

所有 Desense 问题必须从三个维度分析：

```plaintext
┌──────────┐     耦合路径      ┌──────────┐
│  干扰源  │ ───────────────→ │  受扰体  │
│ (Source) │    (Path)         │ (Victim) │
└──────────┘                   └──────────┘
```

## 干扰源 (Source)

**核心问题**：谁在产生噪声？

**措施方向**：展频 / 降频 / 关断

**优先级**：1（最有效）

### 常见干扰源清单

| 大类 | 干扰源模块 | 主要噪声来源 | 典型基频范围 |
|------|------------|--------------|--------------|
| **显示** | LCD MIPI | DSI Clock / Data | 200-800 MHz |
| | LCD 背光 | PWM 调光 / Boost | 10-50 kHz / 1-2 MHz |
| **存储** | DDR | 内存时钟 | 200-933 MHz |
| | eMMC / UFS | 接口时钟 | 50-200 MHz |
| **摄像** | MIPI CSI | 前后摄时钟 | 200-800 MHz |
| | Camera AVDD | 模拟电源噪声 | DC / 低频纹波 |
| **振动** | VIB Motor | PWM 驱动 | 20-50 kHz |
| **音频** | Speaker PA | Class-D 开关频率 | 300-600 kHz |
| **充电** | Charger IC | Buck/Boost 开关 | 500 kHz - 2 MHz |
| **电源** | PMIC Buck | 各路 DCDC 开关 | 1-4 MHz |
| **外设** | USB 3.0 | SS 5Gbps 信号 | 2.5 GHz / 5 GHz |

## 受扰体 (Victim)

**核心问题**：哪个频段被干扰？

**措施方向**：滤波 / 避开频率 / 提高容限

**优先级**：3（最后手段）

| **LTE LB** | B5/8/12/20/26/28 | 700-960 MHz | -94 ~ -102 dBm |

| **GNSS L5** | GPS L5/BDS B2a | 1176 MHz | -140 ~ -150 dBm |

## 耦合路径 (Path)

**核心问题**：怎么传过去的？

**措施方向**：屏蔽 / 隔离 / 接地

**优先级**：2

### 耦合路径分类

| 路径类型 | 描述 | 典型改善措施 |
|----------|------|--------------|
| **传导** | 通过 PCB 走线/电源平面传播 | 滤波 / 隔离 / 分割电源 |
| **辐射** | 通过空间电磁场耦合 | 屏蔽 / 拉远距离 / 吸波材料 |
| **串扰** | 通过相邻走线耦合 | 包地 / 增加间距 / 差分走线 |
| **地弹** | 通过公共地阻抗耦合 | 分割地 / 加强接地 / 星型接地 |

## 优先级原则

1. **干扰源** > **耦合路径** > **受扰体**
2. 软件措施优先于硬件措施
3. 设计查阅优先于事后整改
