# 设计查阅原则

## 核心理念

**分析前先查阅设计资料，看前期规避措施，避免重复劳动。**

## 为什么设计查阅？

1. **避免重复**：已有措施无需重复验证
2. **理解设计**：理解设计意图，避免误判
3. **快速定位**：设计文档中通常有关键信息
4. **合规依据**：设计文档是合规性的重要依据

## 查阅资料清单

### 1. 原理图
- **电源树**：了解电源分布和滤波设计
- **时钟树**：了解时钟分布和展频设计
- **接口定义**：了解信号接口和阻抗匹配

### 2. PCB 设计
- **布局图**：了解模块布局和隔离设计
- **走线规则**：了解关键信号走线规则
- **屏蔽设计**：了解屏蔽罩和接地设计

### 3. 规格书
- **芯片规格书**：了解芯片工作参数和限制
- **模块规格书**：了解模块性能指标
- **认证报告**：了解合规性测试结果

### 4. 测试报告
- **预兼容测试**：了解前期测试结果
- **问题记录**：了解历史问题和解决方案
- **整改记录**：了解整改过程和效果

## 查阅流程

### 第一步：收集资料
1. 获取项目原理图
2. 获取 PCB 设计文件
3. 获取芯片规格书
4. 获取历史测试报告

### 第二步：关键信息提取
1. **电源滤波**：检查电源滤波电容和电感
2. **时钟展频**：检查时钟展频配置
3. **屏蔽设计**：检查屏蔽罩接地和隔离
4. **接口匹配**：检查信号接口阻抗匹配

### 第三步：对比分析
1. 对比设计与实际测试结果
2. 检查设计是否考虑干扰问题
3. 确认是否有规避措施

### 第四步：制定方案
1. 如有规避措施，验证其有效性
2. 如无规避措施，制定整改方案
3. 如设计缺陷，记录并反馈

## 常见设计规避措施

### 1. 电源滤波
- **LC 滤波**：电感+电容滤波
- **π 型滤波**：双电容+电感滤波
- **磁珠滤波**：高频噪声抑制

### 2. 时钟展频
- **SSC 配置**：展频幅度和频率
- **时钟源选择**：低抖动时钟源
- **分频设计**：避免谐波命中

### 3. 屏蔽设计
- **屏蔽罩**：金属屏蔽罩隔离
- **接地设计**：多点接地降低阻抗
- **隔离设计**：模块间物理隔离

### 4. 接口匹配
- **阻抗匹配**：50Ω/100Ω 差分匹配
- **端接设计**：源端/负载端端接
- **走线规则**：等长、差分、包地

## 注意事项

1. **资料完整性**：确保查阅资料完整且最新
2. **版本对比**：注意设计版本与实际量产版本差异
3. **保密要求**：遵守设计资料保密规定
4. **记录归档**：查阅结果需记录归档
