# SOP 编写指南

## SOP 简介

SOP（Standard Operating Procedure，标准作业程序）是 Desense 问题排查的标准化步骤文档。

## SOP 结构

每个 SOP 包含以下章节：

### 1. 组合信息
- 干扰源模块
- 受扰体频段
- 耦合路径类型

### 2. 理论预判
- 谐波命中计算
- 设计审查必查项

### 3. 软件排查步骤
- 场景复现
- 干扰源确认
- 频率验证
- 软件规避尝试

### 4. 硬件排查步骤
- 路径确认
- 硬件整改验证

### 5. 结论模板
- 三要素结论
- 改善措施

### 6. 典型案例
- 历史参考案例

### 7. 检查表
- 步骤检查清单

## SOP 编写流程

### 步骤 1：确定组合
1. 选择受扰体频段
2. 选择干扰源模块
3. 确认耦合路径

### 步骤 2：理论预判
1. 计算谐波命中
2. 列出设计审查项
3. 预判排查重点

### 步骤 3：编写步骤
1. 软件排查步骤（4 步）
2. 硬件排查步骤（2 步）
3. 记录操作和预期结果

### 步骤 4：制定结论
1. 三要素分析
2. 改善措施
3. 状态标记

### 步骤 5：添加案例
1. 收集历史案例
2. 提取关键信息
3. 添加参考链接

## SOP 编写规范

### 格式要求
- 使用 Markdown 格式
- 标题层级清晰
- 列表结构规范
- 代码块使用正确

### 内容要求
- 描述准确
- 步骤详细
- 预期结果明确
- 术语一致

### 更新维护
- 版本管理
- 日期记录
- 状态标记
- 变更日志

## SOP 编写工具

### SOP 快速创建脚本
```bash
./tools/new-sop.sh
```

输入参数：
- 受扰体代码：W24/W5/LLB/LHB/GL1/GL5
- 干扰源代码：LC/CA/DD/PM/VB/SP/CH/U3
- SOP 序号：01-99

### 谐波计算工具
```bash
python3 tools/harmonic_calc.py <base_freq> <harmonic_order> <victim_start> <victim_end>
```

用于理论预判中的谐波命中计算。

## SOP 示例

### SOP-GL1-01：LCD MIPI → GNSS L1

#### 组合信息
- 干扰源：LCD MIPI，基频 200-800 MHz
- 受扰体：GNSS L1，频段 1561-1606 MHz
- 耦合路径：辐射，空间电磁场耦合

#### 理论预判
- 谐波计算：400 MHz × 4 = 1600 MHz ✓ 命中
- 设计审查：LCD 屏蔽罩接地、时钟展频配置

#### 软件排查步骤
1. 场景复现：亮屏常亮，测量 GNSS 灵敏度
2. 干扰源确认：开关测试确认 LCD MIPI
3. 频率验证：测量基频 400MHz，谐波 1600MHz
4. 软件规避：尝试 SSC 展频，记录改善效果

#### 硬件排查步骤
1. 路径确认：近场扫描确认辐射路径
2. 整改验证：屏蔽罩接地优化，验证效果

#### 结论
- 干扰源：LCD MIPI，基频 400MHz
- 受扰体：GNSS L1，敏感度 -140dBm
- 耦合路径：辐射，空间电磁场耦合
- 改善措施：SSC + 屏蔽罩接地，总改善 11dB

## 常见问题

### Q: 如何确定 SOP 编号？
A: 查询矩阵表，(受扰体, 干扰源) 对应唯一编号。

### Q: 如何计算谐波命中？
A: 使用谐波计算工具：`python3 tools/harmonic_calc.py`。

### Q: 如何更新矩阵表？
A: 编辑 `knowledge/matrix/matrix-table.md`。

### Q: 如何添加典型案例？
A: 在 SOP 的"典型案例"章节添加参考链接。
